# 个人网站

> 一个个人作品集与内容站点。视觉方向：**现代工业风 + 冷峻扁平化 + 严谨网格**，
> 融合解构主义、酸性设计、新未来主义与拼贴艺术。
> 一句话定位：**BUILDING USEFUL THINGS WITH CODE**

---

## 技术栈

| 项 | 选型 |
|---|---|
| 框架 | Next.js（App Router）+ TypeScript |
| 部署 | Vercel 全栈 |
| 数据库 | Vercel Postgres |
| 鉴权 | 固定密码 + 环境变量（仅管理员） |
| 统计 | Vercel Analytics |
| 音乐 | 原生 `<audio>`，无第三方播放器库 |

---

## 页面结构

**左侧固定竖栏导航（六项）**：

```
01 首页 HOME        05 留言墙 MESSAGE
02 作品集 WORKS      06 关于 ABOUT
03 笔记 NOTES
04 文章 ARTICLES
```

**路由**

```
/                    启动页          品牌亮相
/home                首页            主视觉 + 四精选作品 + 笔记/文章 + 右栏三块
/work                作品列表         GitHub 项目，按语言筛选 + 排序
/work/[slug]         作品详情         README 渲染 / 排版化空状态
/articles            文章列表         长文
/articles/[slug]     文章阅读
/notes               笔记列表         短碎片
/notes/[slug]        笔记阅读
/about               关于            可编辑内容页（唯一放联系方式的地方）
/guestbook           留言墙          公开免登录
/admin/*             编辑与导入       密码保护

全站常驻：右下角音乐播放器（三态，不单开页面）
```

**首页右栏三块**：① Now Playing 播放器 ② Message Wall 留言入口 ③ 暗色装饰卡（全站唯一暗色区域）

## 内容策略

| 内容 | 来源 |
|---|---|
| **作品项目** | 从 GitHub（[`zhujunkui1-del`](https://github.com/zhujunkui1-del)）自动抓取，README 全文当详情页 |

## 视觉体系速查

| 角色 | 色值 | 用量 |
|---|---|---|
| 主强调（酸性黄） | `#E8FF00` | 每页 1–2 处 |
| 大色块（电光蓝） | `#1E3AFF` | 每页 1 处 |
| 结构（碳黑） | `#0D0D0D` | 文字与细线 |
| 基底（纸白） | `#F9F9F9` | 全站 |

**字体**：Archivo Black（展示）/ Inter（正文）/ JetBrains Mono（界面与元数据）/ 思源黑体（中文）

**五条铁律**
1. 零圆角、无阴影、无柔和渐变（全站统一；暗色装饰卡只换底色不改形状）
2. 每页只有 2–3 个视觉爆点，其余安静有序
3. 1px 结构细线是骨架，必须保留
4. 内容层放开撞色，外壳层克制
5. 动效禁用回弹，统一 `cubic-bezier(0.22, 1, 0.36, 1)`
