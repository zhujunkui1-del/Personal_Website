# 原型说明

> 这是**可交互的 HTML 原型**，用于验证版式与视觉方向。
> **不是最终代码** —— 正式工程为 Next.js，本原型的 CSS 变量与结构可直接迁移。

## 一、怎么打开

原型需要 HTTP 服务（`file://` 下字体与部分资源会被浏览器拦截）。

```powershell
cd "D:\tlydcg\Codex_work\个人网页\原型"
python -m http.server 8099 --bind 127.0.0.1
```

然后浏览器打开：

```
http://127.0.0.1:8099/
```

## 二、本阶段做了什么

**范围：骨架 + 4 个页面**（按约定，播放器留到第二步）

| 文件 | 作用 |
|---|---|
| `assets/tokens.css` | **设计令牌** —— 色板 / 字阶 / 间距 / 缓动 / 断点。全站唯一数值来源 |
| `assets/base.css` | 重置、排版基类、1px 线系统、装饰件（套准标记 / 条形码 / CMYK / 网点 / 斜带） |
| `assets/components.css` | 左竖栏、顶栏、作品卡、区块标题、页脚、骨架屏、空状态、Markdown 渲染 |
| `assets/pages.css` | 启动页 / 首页 / 作品列表 / 作品详情 / 鼠标坐标层 |
| `assets/app.js` | 滚动入场、鼠标坐标层、主视觉粒子与视差 |
| `assets/data.js` | **作品数据（真实 GitHub 数据）** |
| `index.html` `home.html` `work.html` `work-detail.html` | 4 个页面 |

### 已实现的动效

| 动效 | 位置 | 规格 |
|---|---|---|
| 巨字揭示 | 启动页 | 英文逐字（40ms 间隔）/ 中文整行上推 |
| 黄带扫过 | 启动页 | `clip-path` 从左展开，1200ms |
| 滚动入场 | 全站 | `translateY(24px) → 0`，600ms，**每块只触发一次** |
| 卡片 hover | 作品卡 | 图片 `scale(1.02)` 400ms + 撞色块位移 8px |
| 箭头 hover | 全站 | 水平位移 8px，200ms |
| 状态灯呼吸 | 顶栏 | 2400ms 循环 |
| **鼠标坐标层** | 首页首屏 | 极淡网格 + 局部十字（各 200px）+ 黄点 + 等宽坐标读数 |
| **粒子 + 鼠标排斥** | 首页主视觉 | 30–58 个极淡方点/小十字，120px 内被推开 |
| **视差位移** | 首页主视觉 | 鼠标反向 ±12px，`lerp 0.08` 平滑 |

### 已落实的设计规则

- **零圆角**全站统一（**播放器不再是例外** —— 已按设计稿改为纸白实色）
- 图片**保持彩色**，不做去饱和
- 左竖栏六项：图标 + 中文（上）+ 极小英文（下）
- 当前项左侧 3px 酸性黄竖条
- **空状态**：README 为 0 字节时展示「项目进行中 / IN PROGRESS」，不编造内容
- **出处标注**：作品详情元数据表含 `GITHUB ↗` 链接与 `SOURCE` 来源标注
- 键盘焦点用像素风描边（非浏览器默认蓝框）
- `prefers-reduced-motion` 时关闭全部动画

## 三、数据从哪来

`assets/data.js` 由 `tools/_build_data.mjs` 生成，抓取自真实的 GitHub 账号。

```
实测结果（5 个原创仓库，排除 3 个 fork）：

仓库                                 封面   README      语言
─────────────────────────────────────────────────────────────────
Zhihu_ZhiYu                         无     0 字符       HTML 81% / TS 16%
Intelligent-Service-Assistant       有     1485 字符    Python 100%
Dagou_Game                          有     386 字符     HTML 100%
Student-Dormitory-Management-System 无     2606 字符    JS 77% / CSS 9%
Guangdong-Weather-                  无     67 字符      Python 100%
```

**封面策略**（三层保底，已实测）：
1. README 第一张图自动取 —— 2/5 个仓库命中
2. 未命中时回退到 `media/default-cover.png`
3. 可手动覆盖（编辑器，第二步）

> 相对路径（`./素材/show.png`）会解析为
> `https://raw.githubusercontent.com/{user}/{repo}/{默认分支}/{路径}`
> 分支名读 API 的 `default_branch`（仓库 master/main 混用）
> 路径含中文时需 URL 编码 —— 代码里做了**解码后比较**去重

## 四、原型的已知限制

| # | 限制 | 说明 |
|---|---|---|
| 1 | **播放器未实现** | 右栏与启动页的播放器是**静态占位**。第二步接真实 `<audio>` |
| 2 | **跨页播放未实现** | 静态 HTML 无「根布局」，切页会重建。需 Next.js 阶段用 Context 实现 |
| 3 | **文章 / 笔记是占位内容** | 首页与列表页的笔记文章为示例文字，你还没有真实内容 |
| 4 | **关于页 / 文章页 / 笔记页 / 留言墙未做** | 属第二步范围 |
| 5 | **字体走 Google Fonts CDN** | 正式工程改为自托管 woff2 |
| 6 | **数据是构建时写死的** | 正式工程由 `/api/works` 动态获取，结构保持一致 |
| 7 | **作品详情只渲染 README** | 未做图片灯箱、目录跳转、代码高亮 |
| 8 | **后台页面未做** | 总览 / 作品管理 / 关于编辑属第二步 |
| 9 | **鼠标坐标层仅桌面** | 触屏设备与 `prefers-reduced-motion` 下自动关闭 |
| 10 | **无头浏览器窄屏渲染偏差** | 无头 Chrome 在 <500px 窗口会把布局视口强制到 478px，导致手机底栏第 6 个图标在截图中被裁。**真实浏览器不受影响**，请以实际浏览器为准 |

## 六、怎么改

**改设计数值** → 只改 `assets/tokens.css`，全站生效。

**改页面结构** → 对应 `.html`；共享组件（竖栏/顶栏/页脚）在 4 个页面里是复制粘贴的，
改一处需同步四处。**这是原型阶段的取舍** —— 正式工程会抽成组件。

**重新抓取 GitHub 数据**：

```powershell
cd "D:\tlydcg\Codex_work\个人网页"
# 1) 用 PowerShell 抓（本机 Node fetch 有证书问题；Vercel 上无此问题）
#    产物在 %TEMP%\gh_readmes\
# 2) 生成 data.js
node tools\_build_data.mjs
```

**校验原型完整性**：

```powershell
cd 原型
node _verify.js
```

## 七、与正式工程的关系

| 项 | 原型 | 正式工程 |
|---|---|---|
| 设计令牌 | `tokens.css` | → **原样迁移**为 CSS 变量 / Tailwind 配置 |
| 共享组件 | 复制粘贴 | → 抽成 React 组件 |
| 页面 | 独立 HTML | → App Router 路由 |
| 数据 | `data.js` 写死 | → `/api/works` 动态获取 |
| 播放器 | 静态占位 | → 根布局常驻，跨页不断 |
| 字体 | Google CDN | → 自托管 woff2 |

**能直接复用的**：`tokens.css` 全部、`base.css` 大部分、装饰件（套准标记/条形码/CMYK/网点）、
`app.js` 里的坐标层与粒子逻辑。
