## 三、站点框架速览

### 导航（左侧固定竖栏，六项）
```
01 首页 HOME        04 文章 ARTICLES      关于页另可从顶栏品牌区进入
02 作品集 WORKS      05 留言墙 MESSAGE
03 笔记 NOTES       06 关于 ABOUT
```

### 页面地图
```
/                    启动页       品牌亮相
/home                首页         主视觉 + 四精选作品 + 笔记/文章 + 右栏三块
/work                作品列表     网格 + 语言筛选 + 排序
/work/[slug]         作品详情     README 渲染 / 排版化空状态
/admin/import        作品批量导入  拖拽 + 数据表
/articles            文章列表     长文
/articles/[slug]     文章阅读
/admin/articles      文章编辑
/notes               笔记列表     短内容
/notes/[slug]        笔记阅读
/admin/notes         笔记编辑
/about               关于/联系
/guestbook           留言墙
全站常驻              右下角音乐播放器（不单开页面）
```

### 三个层次
```
展示层  作品集 · 名片
内容层  文章 + 笔记
交互层  留言墙 · 音乐播放器
```

**文章 vs 笔记**（刻意区分，否则两个板块会长得一样）：
| | 文章 | 笔记 |
|---|---|---|
| 内容 | 长文、教程、方法论 | 灵感碎片、快速记录 |
| 阅读 | 窄栏长文 | 浮动卡片 + 相关推荐 |
| 编辑 | 双栏（正文+侧栏） | 单写作面（极简） |

### 技术架构
```
Vercel 全栈
├── 静态页面（SSG/ISR）
├── Serverless API（编辑 / 导入 / 鉴权）
└── 数据库 + 对象存储
留言墙 → 第三方服务
音乐   → 静态音频，版权由作者提供
```

## 四、视觉体系速查

### 三种艺术主义
```
骨架   瑞士国际主义      栅格、巨型无衬线、零圆角、1px 结构线
语法   HUD / 战术遥测    编号、等宽元数据、CMYK 套准标记、条形码
表现   解构 / 酸性 / 拼贴  斜向色带、色块碰撞、贴纸、描边字
```

### 色板
| 角色 | 色值 | 用量上限 |
|---|---|---|
| 唯一强调色 | 酸性荧光黄 `#E8FF00` | 1–2 处 / 页 |
| 大色块 | 电光蓝 `#1E3AFF` | 1 处 / 页 |
| 结构 | 碳黑 `#0D0D0D` | 文字与细线 |
| 基底 | 纸白 `#F9F9F9` | 全站 |
| 小警报 | 洋红 `#FF2B8A` / 橙红 `#FF4422` | 点缀 |

### 五条铁律
1. **零圆角、无阴影、无柔和渐变** —— 全站
2. **每页只有 2–3 个视觉爆点**，其余安静有序
3. **1px 结构细线是骨架，必须保留** —— 这不属于"黑线太多"
4. **内容层放开撞色，外壳层保持克制**
5. **动效禁用回弹** —— 缓动统一 `cubic-bezier(0.22, 1, 0.36, 1)`

## 五、开工前还差三件事

| # | 待决 | 影响 |
|---|---|---|
| 1 | **内容导入方案**：Markdown+Git / 数据库+API / 本地工具 | 决定技术栈与工期 |
| 2 | **字体引入**：展示级字重（Archivo Black / Monument Extended）需自托管 | 没字体做不出巨字效果 |
| 3 | **版权确认**：字体授权 + 音乐授权 | 法律风险，不确认不上线 |

### 已确认的事项
- ✅ 部署：Vercel 全栈，不依赖外部站点做前后端
- ✅ 留言墙：接受第三方服务
- ✅ 音乐：作者自备音频
- ✅ 播放器：常驻小图标 + 点击唤醒，含歌单/音量/进度/上下首/循环随机
- ✅ 作品量少，但仍保留作品列表页

## 六、历史版本说明
