## `主视觉/` — 首页主视觉

由风格基准图**图生图重绘**得到，**已去除全部 UI 文字与界面元素**。

| 文件 | 尺寸 | 构图 | 状态 |
|---|---|---|---|
| `主视觉-01-横向.png` | 1536×1024 | 元素较满，人物偏左 | 弃用 |
| `主视觉-02-紧凑.png` | 1254×1254 | 近方形，构图饱满 | **保留备用** |
| **`主视觉-03-宽幅.png`** | 1536×1024 | 大量留白，黄带斜穿 | ★ **已采用** |

**采用 03 的理由**：
1. 留白最多，符合「每页 2–3 个视觉爆点，其余安静」的纪律
2. 含斜向黄带 —— 视觉体系的核心元素
3. 构图弹性最好，元素集中、四周空白，便于按屏宽裁切适配

**02 的去向**：留作**方形场景**备用（分享卡片、关于页等）。

**共同特征**：厚涂笔触 · 酸性黄大圆 · 电光蓝色块 · 灰白建筑山峦拼贴 · 飞溅墨迹 · 坐标十字 · 半调网点。

> ⚠️ **三张都没有透明通道**（PNG 但无 alpha），底色是纸白 `#F9F9F9`。
> 页面底色同为纸白，**直接使用无边界问题**；
> 若将来需叠在非纸白背景上，需另行抠图或重新以透明背景生成。

## `portrait.jpg` — 关于页肖像

| 项 | 值 |
|---|---|
| 内容 | 日系插画：金发角色 / 深蓝夜空 / 金色散景 |
| 格式 | JPEG |
| 尺寸 | **954 × 954** |
| 大小 | 99 KB |
| 来源 | 作者的 GitHub 头像 |
| 用途 | 关于页右侧肖像位（对应参考图 `05-关于与留言/01-关于联系.jpg` 里的照片位置） |

### 设计注意
这是**页面上唯一的饱和色彩区域**，而站点是纸白 + 黑 + 混凝土灰度 + 酸性黄的冷峻体系。

**已决定：保持原图**，不做灰度、不做双色调。

因此实现时需要：
- 外层加**细边框**（1px），与纸白基底明确分隔
- **避免与黄斜带、蓝块直接相邻** —— 否则色彩会互相干扰
- 按"内容色岛"处理：外壳克制，这一块放开

### 限制
原图 954×954，**显示宽度超过约 500px 会偏糊**。

## `default-cover.png` — 项目默认图

| 项 | 值 |
|---|---|
| 内容 | 线稿占位：白底 + 虚线轮廓 + 手写片假名 `アッカリーン` |
| 格式 | PNG（已从 WEBP 转换，见下方说明） |
| 尺寸 | **500 × 500** |
| 大小 | 43 KB |
| 用途 | 项目/作品**没有截图时**的默认缩略图 |

### 设计注意
白底 + 黑色虚线，而站点底色是纸白 `#F9F9F9`。

**已决定：保持原样**，不加浅灰底衬、不做反白。

因此实现时：
- 缩略图区域内会出现**边界弱化**效果（白底融入纸白背景，只剩虚线与手写字）
- 排成一行时靠**外边距与下方元数据行**维持视觉节奏
- 这个"等待填充"的观感可以视为有意为之

### 格式说明
原文件 `网站默认图片.png` 的**扩展名与真实格式不符**（`.png` 实际是 WEBP）。
已转换为标准 PNG，**画面内容与白底完全不变**，仅修复格式一致性。

### 限制
仅 500×500，作品卡放大显示时会偏糊。
