# 动效与交互规格

> 本文档定义全站的动效体系、交互状态、特殊视觉效果。
> 与 `08-施工说明书.md` 配合使用，冲突时以施工说明书为准。

---

## 一、动效语气

站点是「**工程图纸 + 印刷事故**」。动效应像**印刷机的机械动作**，不像手机的弹簧动画。

| 该有 | 禁止 |
|---|---|
| 位移、裁切、硬边揭示 | 弹性回弹、果冻感 |
| 机械精度、线性节奏 | 柔软缓动、过冲 |
| 色带扫过、遮罩擦除 | 缩放弹跳、旋转漂浮 |
| 慢而确定（400–1200ms） | 快而漂浮（150ms 弹入） |

---

## 二、缓动曲线

```css
--ease-standard: cubic-bezier(0.22, 1, 0.36, 1);   /* 全站默认，先快后缓 */
--ease-in:       cubic-bezier(0.16, 1, 0.3, 1);    /* 元素进入，更陡 */
--ease-out:      cubic-bezier(0.7, 0, 0.84, 0);    /* 快速离开 */
--ease-linear:   linear;                            /* 进度条、旋转、跑马灯 */
```

**明令禁止**：`bounce` / `elastic` / `back` / 任何回弹曲线。

---

## 三、时长刻度

| 令牌 | 时长 | 用途 |
|---|---|---|
| `--dur-instant` | 120ms | 颜色变化、hover 变色 |
| `--dur-fast` | 200ms | 箭头位移、按钮反馈、下划线展开 |
| `--dur-base` | 400ms | 卡片 hover、图片揭示、播放器面板 |
| `--dur-slow` | 700ms | 区块入场、页面转场 |
| `--dur-xslow` | 1200ms | 启动页揭示、黄带扫过 |

## 四、动效清单

### 4.1 启动页揭示序列（总计约 1200ms）

```
0ms      巨字逐字上推（英文逐字 / 中文整行）
          translateY(100%) → 0，每字延迟 40ms
400ms    黄带从左向右扫过（clip-path 展开）
800ms    副标题淡入
1000ms   四条编号导航依次出现，每条延迟 80ms
1200ms   完成，等待用户点击
```

**退出**：点击「进入」后整页向上滑出，`translateY(-100%)`，700ms。

### 4.2 页面转场 ★（2026-09-13 修正）

> **修正原因**：新设计稿的**主视觉本身就带斜向黄带**。
> 如果转场再来一条黄带扫过，会与主视觉撞车、显得黄带遍地都是。
> 作者决定：**取消黄带转场**。

| 场景 | 动效 | 时长 |
|---|---|---|
| **所有页面切换** | **快速淡入**（`opacity 0 → 1`） | **150ms** |
| 返回上一级 | 同快速淡入 | 150ms |

> 原「黄带扫过全屏」方案（深层 700ms / 同级 200ms）**已作废**。
> 理由：更快的切换对多页站点更友好，也把黄带留给主视觉独占。

### 4.3 滚动入场 ★（2026-09-13 修正）

> **修正原因**：新首页区块更多（主视觉 + 四作品卡 + NOTES + ARTICLES + 右栏三块），
> 旧规格的「只前 3 个区块」不够用。

```
触发：元素进入视口 20%
动效：translateY(24px) → 0，opacity 0 → 1
时长：600ms，标准缓动
范围：首屏以下的【所有区块】，每块各触发一次
重复：不重复（同一次浏览内只播一次）
```

**各区块的入场顺序**（依次延迟 80ms，形成节奏）：
```
1. 主视觉（首屏，随页面加载直接入场）
2. FEATURED WORKS 作品卡行
3. NOTES 笔记区 + ARTICLES 文章区（同批）
4. 右栏三块（播放器 / 留言入口 / 暗色卡，依次延迟）
```

### 4.4 黄带揭示

滚动到位置时，`clip-path` 从左侧展开，800ms。
用于区块标题背后的黄色块。

### 4.5 ~~主视觉轮播~~ ★已取消

> **2026-09-13**：作者决定取消轮播，改为**单张静态主视觉 + 粒子动效**。
> 原轮播参数（横向位移 600ms / 计数滚动 300ms）**作废**。
> 新方案见 §5.4。

### 4.6 作品卡 hover ★（2026-09-13 修正）

```
图片：轻微放大 scale(1.02)，400ms
     （原「grayscale → 原色」已作废 —— 图片保持彩色）
撞色块：位移 8px，200ms
元数据行：向上推 2px
```

### 4.7 微交互

| 元素 | 动效 | 时长 |
|---|---|---|
| 箭头 `→` | hover 水平位移 8px | 200ms |
| 导航下划线 | 从左侧展开 | 200ms |
| 状态灯 `● ONLINE` | 透明度呼吸循环（1 → 0.35） | 2400ms |
| 编号计数 | 数字垂直滚动替换 | 300ms |
| 图片加载 | 模糊占位 → 清晰 | 500ms |

### 4.8 播放器 ★（2026-09-13 重写）

> **修正原因**：新设计稿里首页右栏**内嵌**了播放器，
> 且作者确认：**首页右栏常驻播放器不用折叠态**，其他页用三态。

#### 位置与形态（两套）

| 页面 | 位置 | 形态 |
|---|---|---|
| **首页** | 右栏第一块（常驻） | **两态**：主屏 → 歌单展开（**无折叠态**） |
| **其他所有页面** | 贴**右边缘**固定 | **三态**：折叠标签 → 主屏 → 歌单展开 |
| 后台页面 | 同样贴右边缘 | 同其他页 |

#### 折叠态规格

```
尺寸      54 × 117 px
位置      贴页面右边缘，垂直方向约居中
外观      【直角实色】纸白面板 + 1px 描边，内含一个箭头
          （视觉基准：06-组件/01-音乐播放器.png 的「01 折叠态」）
激活方向  箭头朝左 → 面板【向左侧展开】，不遮挡页面中间内容
```

#### 展开面板

```
主屏      约 498 × 285
歌单      约 498 × 660（在主屏下方继续撑开）
贴边方式  固定贴右侧边缘，左侧留出页面主流内容
```

#### 跨页持续播放 ★

```
从首页切到其他页（或任意页互切）：
  · 音乐【不停】
  · 播放进度保留
  · 音量保留
  · 播放模式保留
  · 歌单与当前曲目保留

技术要点：
  · 播放器挂在根布局（layout），不随页面卸载
  · 首页右栏那块与其他页的浮层是【同一个播放器实例】
  · 用 React Context 或全局状态共享
  · 路由切换不能重建 <audio> 元素
```

#### 黑胶旋转 ★

| 元素 | 动效 | 时长 |
|---|---|---|
| **黑胶** | 线性连续旋转，约 **3 秒/圈** | 连续 |
| 暂停 | `animation-play-state: paused`，**从停住角度继续** | — |
| 无封面 | **不显示黑胶** | — |
| `prefers-reduced-motion` | **不旋转** | — |

#### 展开 / 收起动效

| 动作 | 动效 | 时长 |
|---|---|---|
| 折叠标签 → 主屏 | 从右侧滑入（实色面板，**无模糊**） | 400ms |
| 主屏 → 歌单展开 | 高度 0 → 自适应撑开 | 400ms |
| 收起 → 折叠标签 | 反向滑出 | 300ms |
| 收起方式 | 点面板外部关闭 | — |

### 4.9 留言墙

```
新增留言：从顶部滑入，500ms
          + 高亮一次（黄底闪烁后淡出），800ms
```

### 4.10 骨架屏

数据加载时（GitHub 抓取有延迟）：

```
浅灰块（#E6E5E1）作底 + 黄块（#E8FF00）闪烁
闪烁周期：1400ms，线性
形状：与真实内容同构（不跳版）
```

## 五、特殊视觉效果

### 5.1 鼠标坐标层 ★

> 示意图：`../02-页面参考图/06-组件/02-鼠标坐标层示意.jpg`

**范围**：**仅首屏区域**。向下滚动进入内容区后消失。

**三态**：

| 状态 | 表现 |
|---|---|
| **静止** | 背景极淡网格（**约 4% 不透明度**），几个 `⊹` 定位标记 |
| **鼠标移动** | 网格略微浮现；鼠标位置画**一横一竖两条短线**（各延伸约 200px）；交叉点一个**黄方块**；旁边跟**等宽坐标读数框**（`X 0842 / Y 0317`） |
| **移到图片上** | 网格与短线叠在图上；读数框变**黑底白字**保证可读 |

**实现要点**：
- 网格用 CSS `repeating-linear-gradient` 或 SVG pattern
- 十字线用 `transform: translate()` 跟随，`will-change: transform`
- 坐标读数用 `requestAnimationFrame` 节流，不每帧重渲
- **不透明度必须压到约 4%** —— 示意图上偏明显，实做会干扰阅读

### 5.2 标题逐字入场

| 语言 | 处理 |
|---|---|
| **英文** | 按字符拆分，逐字 `translateY(100%) → 0`，每字延迟 40ms |
| **中文** | **整行上推**（不做逐字） |

> 理由：汉字等宽，逐字上推会出现字距抖动。整行上推视觉上仍统一。

### 5.3 图片扫描线

- 图片上叠加极淡的**水平扫描线纹理**
- hover 时一条亮线**自上而下扫过**（约 600ms）
- 仅用于作品图与文章封面，不用于肖像

### 5.4 首页主视觉动效 ★（2026-09-13 新增）

**已取消轮播**，改为「单张静态图 + 动效」。

#### ① 漂浮粒子 + 鼠标排斥

```
粒子数量     30–60 个（视屏幕宽度）
粒子外观     极淡的小方块或小十字（非圆点，贴合 HUD 语言）
             颜色 rgba(13,13,13,0.15) 或酸性黄 5%
运动方式     缓慢漂浮，各自有随机的速度与方向
鼠标交互     光标半径 120px 内的粒子被推开（排斥力随距离衰减）
             移开鼠标后粒子缓慢回归原轨迹
性能         Canvas 或 CSS transform，requestAnimationFrame 驱动
             devicePixelRatio 适配，避免高分屏模糊
```

**禁止**：明亮的粒子、发光效果、连线成网（那是常见科技风，与本设计体系不符）。

#### ② 鼠标视差位移

```
主视觉图片   随鼠标位置做小幅反向位移
最大位移     约 ±12px（超过会晕）
缓动         用 lerp 平滑跟随（系数 0.08），不要硬跟
图层分层     图片 1 层，粒子 1 层，位移幅度不同形成纵深
```

#### ③ 降级

| 条件 | 处理 |
|---|---|
| `prefers-reduced-motion: reduce` | **完全关闭**粒子与视差 |
| 触屏设备 | 关闭鼠标排斥与视差（无光标），粒子保留缓慢漂浮 |
| 低端设备 | 粒子数降到 20，或直接关闭 |
| 页面不可见（`visibilitychange`） | **暂停渲染**，节省电量 |

## 六、交互状态

### 6.1 键盘焦点（无障碍必需）

**不用浏览器默认蓝框**，改为**像素风描边**：

```css
:focus-visible {
  outline: 2px solid #0D0D0D;
  outline-offset: 2px;
}
```

深色背景上改用酸性黄 `#E8FF00`。

### 6.2 已访问链接

已访问的链接用**灰色文字 + 下划线**区分，与未访问的黑字形成对比。

### 6.3 按钮按下位移

```css
button:active { transform: translateY(1px); }
```
像真的按到印刷按钮。

### 6.4 禁用态

```css
[disabled] {
  opacity: 0.4;
  cursor: not-allowed;
  pointer-events: none;
}
```

## 七、无障碍降级 ★

系统开启「**减少动效**」时：

```css
@media (prefers-reduced-motion: reduce) {
  /* 关闭全部动画 */
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

**同时关闭**：
- 鼠标坐标层
- 标题逐字入场
- 黑胶旋转
- 状态灯呼吸
- 骨架屏闪烁（改为静态浅灰块）
- 图片扫描线

**保留**：所有内容正常显示，只是没有动画。

| M9 | 十字线长度 | **局部短线**（各延伸约 200px） |

## 九、实现注意

| 项 | 要求 |
|---|---|
| 性能 | 只动 `transform` 与 `opacity`，不动 `width/height/top/left` |
| 加速度 | 长列表/轮播用 `will-change` 但用完即撤 |
| 节流 | 鼠标跟随用 `requestAnimationFrame` |
| 首屏 | 动画不阻塞首屏渲染，`prefers-reduced-motion` 优先判定 |
| 移动端 | 鼠标坐标层在触屏设备**不启用** |
| 测试 | 每项动效在低端设备与「减少动效」模式下都要验证 |
