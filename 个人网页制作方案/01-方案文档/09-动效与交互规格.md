# 动效与交互规格

> 本文档定义全站的动效体系、交互状态、特殊视觉效果。
> 与 `08-施工说明书.md` 配合使用，冲突时以施工说明书为准。

---

## 一、动效语气

站点是「**工程图纸 + 印刷事故**」。动效应像**印刷机的机械动作**，不像手机的弹簧动画。

| 该有 | 禁止 |
|---|---|
| 位移、裁切、硬边揭示 | 弹性回弹、果冻感 |
| 机械精度、线性节奏 | 柔软缓动、过冲 |
| 色带扫过、遮罩擦除 | 缩放弹跳、旋转漂浮 |
| 慢而确定（400–1200ms） | 快而漂浮（150ms 弹入） |

---

## 二、缓动曲线

```css
--ease-standard: cubic-bezier(0.22, 1, 0.36, 1);   /* 全站默认，先快后缓 */
--ease-in:       cubic-bezier(0.16, 1, 0.3, 1);    /* 元素进入，更陡 */
--ease-out:      cubic-bezier(0.7, 0, 0.84, 0);    /* 快速离开 */
--ease-linear:   linear;                            /* 进度条、旋转、跑马灯 */
```

**明令禁止**：`bounce` / `elastic` / `back` / 任何回弹曲线。

---

## 三、时长刻度

| 令牌 | 时长 | 用途 |
|---|---|---|
| `--dur-instant` | 120ms | 颜色变化、hover 变色 |
| `--dur-fast` | 200ms | 箭头位移、按钮反馈、下划线展开 |
| `--dur-base` | 400ms | 卡片 hover、图片揭示、播放器面板 |
| `--dur-slow` | 700ms | 区块入场、页面转场 |
| `--dur-xslow` | 1200ms | 启动页揭示、黄带扫过 |

## 四、动效清单

### 4.1 启动页揭示序列（总计约 1200ms）

```
0ms      巨字逐字上推（英文逐字 / 中文整行）
          translateY(100%) → 0，每字延迟 40ms
400ms    黄带从左向右扫过（clip-path 展开）
800ms    副标题淡入
1000ms   四条编号导航依次出现，每条延迟 80ms
1200ms   完成，等待用户点击
```

**退出**：点击「进入」后整页向上滑出，`translateY(-100%)`，700ms。

### 4.2 页面转场（分层）

| 场景 | 动效 | 时长 |
|---|---|---|
| **从首页进入深层页面** | 一条黄带从左侧扫过全屏遮住旧页，再扫出露出新页 | 700ms |
| **同级切换**（文章↔文章、作品↔作品） | 快速淡入 | 200ms |
| **返回上一级** | 反向黄带 | 500ms |

> 理由：黄带转场很帅，但强制等待 700ms。连点三次链接就要等 2 秒。因此只在"进入深层"时使用。

### 4.3 滚动入场（仅前 3 个区块）

```
触发：元素进入视口 20%
动效：translateY(24px) → 0，opacity 0 → 1
时长：600ms，标准缓动
重复：不重复（只触发一次）
范围：仅首屏以下前 3 个区块，之后内容直接就位
```

> 理由：每个区块都做会导致长文阅读时页面不断"跳"。

### 4.4 黄带揭示

滚动到位置时，`clip-path` 从左侧展开，800ms。
用于区块标题背后的黄色块。

### 4.5 主视觉轮播

```
切换：横向位移，600ms
计数：01 / 04 数字垂直滚动替换，300ms
自动：是
```

### 4.6 作品卡 hover

```
图片：filter grayscale(1) → grayscale(0)，400ms
撞色块：位移 8px，200ms
元数据行：向上推 2px
```

### 4.7 微交互

| 元素 | 动效 | 时长 |
|---|---|---|
| 箭头 `→` | hover 水平位移 8px | 200ms |
| 导航下划线 | 从左侧展开 | 200ms |
| 状态灯 `● ONLINE` | 透明度呼吸循环（1 → 0.35） | 2400ms |
| 编号计数 | 数字垂直滚动替换 | 300ms |
| 图片加载 | 模糊占位 → 清晰 | 500ms |

### 4.8 播放器

| 元素 | 动效 | 时长 |
|---|---|---|
| 面板展开 | 从右下角滑出 + 玻璃模糊渐显 | 400ms |
| 歌单展开 | 高度 0 → 自适应撑开 | 400ms |
| **黑胶旋转** | 线性连续旋转，约 3 秒/圈 | 连续 |
| 黑胶暂停 | `animation-play-state: paused`，**从停住角度继续** | — |
| 播放器收起 | 点面板外部，反向滑出 | 300ms |

### 4.9 留言墙

```
新增留言：从顶部滑入，500ms
          + 高亮一次（黄底闪烁后淡出），800ms
```

### 4.10 骨架屏

数据加载时（GitHub 抓取有延迟）：

```
浅灰块（#E6E5E1）作底 + 黄块（#E8FF00）闪烁
闪烁周期：1400ms，线性
形状：与真实内容同构（不跳版）
```

## 五、特殊视觉效果

### 5.1 鼠标坐标层 ★

> 示意图：`../02-页面参考图/06-组件/02-鼠标坐标层示意.jpg`

**范围**：**仅首屏区域**。向下滚动进入内容区后消失。

**三态**：

| 状态 | 表现 |
|---|---|
| **静止** | 背景极淡网格（**约 4% 不透明度**），几个 `⊹` 定位标记 |
| **鼠标移动** | 网格略微浮现；鼠标位置画**一横一竖两条短线**（各延伸约 200px）；交叉点一个**黄方块**；旁边跟**等宽坐标读数框**（`X 0842 / Y 0317`） |
| **移到图片上** | 网格与短线叠在图上；读数框变**黑底白字**保证可读 |

**实现要点**：
- 网格用 CSS `repeating-linear-gradient` 或 SVG pattern
- 十字线用 `transform: translate()` 跟随，`will-change: transform`
- 坐标读数用 `requestAnimationFrame` 节流，不每帧重渲
- **不透明度必须压到约 4%** —— 示意图上偏明显，实做会干扰阅读

### 5.2 标题逐字入场

| 语言 | 处理 |
|---|---|
| **英文** | 按字符拆分，逐字 `translateY(100%) → 0`，每字延迟 40ms |
| **中文** | **整行上推**（不做逐字） |

> 理由：汉字等宽，逐字上推会出现字距抖动。整行上推视觉上仍统一。

### 5.3 图片扫描线

- 图片上叠加极淡的**水平扫描线纹理**
- hover 时一条亮线**自上而下扫过**（约 600ms）
- 仅用于作品图与文章封面，不用于肖像

## 六、交互状态

### 6.1 键盘焦点（无障碍必需）

**不用浏览器默认蓝框**，改为**像素风描边**：

```css
:focus-visible {
  outline: 2px solid #0D0D0D;
  outline-offset: 2px;
}
```

深色背景上改用酸性黄 `#E8FF00`。

### 6.2 已访问链接

已访问的链接用**灰色文字 + 下划线**区分，与未访问的黑字形成对比。

### 6.3 按钮按下位移

```css
button:active { transform: translateY(1px); }
```
像真的按到印刷按钮。

### 6.4 禁用态

```css
[disabled] {
  opacity: 0.4;
  cursor: not-allowed;
  pointer-events: none;
}
```

## 七、无障碍降级 ★

系统开启「**减少动效**」时：

```css
@media (prefers-reduced-motion: reduce) {
  /* 关闭全部动画 */
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

**同时关闭**：
- 鼠标坐标层
- 标题逐字入场
- 黑胶旋转
- 状态灯呼吸
- 骨架屏闪烁（改为静态浅灰块）
- 图片扫描线

**保留**：所有内容正常显示，只是没有动画。

## 八、决策速查

| 组 | 问题 | 决定 |
|---|---|---|
| M1 | 动效强度 | **中等** —— 加滚动入场与关键揭示，不做全套 |
| M2 | 页面转场 | **分层**：深层用黄带扫过，同级快速淡入 |
| M3 | 滚动入场 | 只前 3 个区块，不重复 |
| M4 | 特殊效果 | 坐标网格 ✓ / 标题逐字 ✓ / 图片扫描线 ✓ |
| M5 | 标题拆分 | 英文逐字，中文整行 |
| M6 | 坐标层范围 | **仅首屏** |
| M9 | 十字线长度 | **局部短线**（各延伸约 200px） |
| M10 | 启动页揭示 | 完整序列，约 1.2s |
| M11 | 减少动效降级 | **关闭全部动画** |

## 九、实现注意

| 项 | 要求 |
|---|---|
| 性能 | 只动 `transform` 与 `opacity`，不动 `width/height/top/left` |
| 加速度 | 长列表/轮播用 `will-change` 但用完即撤 |
| 节流 | 鼠标跟随用 `requestAnimationFrame` |
| 首屏 | 动画不阻塞首屏渲染，`prefers-reduced-motion` 优先判定 |
| 移动端 | 鼠标坐标层在触屏设备**不启用** |
| 测试 | 每项动效在低端设备与「减少动效」模式下都要验证 |
