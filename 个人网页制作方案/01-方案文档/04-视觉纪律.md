# 视觉纪律 — 防止风格退化

> 建立原因：在生成功能页参考图时，我为了满足"别压抑、别黑线太多"的反馈，
> 把 prompt 一路往"明亮、干净、留白"收，结果把**解构主义 / 酸性 / 新未来主义 / 拼贴**
> 的风格本身抹平了，产出变成保守的通用模板。
> 本文件用于**约束后续所有出图与开发**，防止同样的事再发生。

---

## 一、根本错误：把"可读性"凌驾于"风格"之上

我加的约束 → 造成的损失：

| 我加的约束 | 损失了什么 |
|---|---|
| `very FEW black dividing lines` | 瑞士骨架的**线框结构感** |
| `airy, bright, clean, minimal` | 拼贴的**层次与密度** |
| `no warped shapes` | 旋转、错位、撕纸 |
| 强调色只留黄/蓝/橙小色块 | **酸性撞色**（黄+蓝+洋红+CMYK） |
| 全部正放、对齐、等距 | 解构的**破坏性** |

**正确的做法**：用户嫌"压抑、黑线多"时，该调整的是**密度与呼吸**，
不是**拆掉风格**。风格元素（斜切、拼贴、套准标记、网点、撞色）一个都不能少。

---

## 二、风格元素清单（出图与开发时必须逐项检查）

### 必须存在（缺一即风格退化）

| 元素 | 说明 |
|---|---|
| **斜向色带** | 黄/蓝色带以 12°–35° 切穿画面，可交叉、可溢出边界 |
| **色块碰撞** | 电光蓝大色块与酸性黄**大面积交叠**，不是小方块点缀 |
| **CMYK 套准标记** | 四角或边距的十字套准 + C/M/Y/K 四色小方块 |
| **条形码条** | 竖排细条纹，作边缘装饰 |
| **贴纸标签** | 黑底白字 / 黄底黑字的胶囊或矩形，直接压在图上 |
| **半调网点** | halftone dot 纹理，覆盖在图片或背景局部 |
| **旋转与错位** | 元素偏离轴线、网格**故意不对齐** |
| **撕纸边缘** | torn / ripped edges，打破矩形边界 |
| **巨型幽灵数字** | 描边（outlined）大号数字衬在内容之后 |
| **等宽字元数据** | 全大写、字距放宽、小字号 |
| **厚涂插画** | 有笔触质感的插画，**保持原色** |

> ⚠️ **2026-09-13 修正**：旧的「**去饱和图 + 直角色块叠加**」公式**已作废**。
> 作者确认图片**保持彩色**（贴合当前设计稿的厚涂插画风格）。
> 色彩统一改靠：**黄蓝色块叠加 + 图表化构图 + 一致的边框与元数据**，不靠去饱和。

### 强烈建议

| 元素 | 说明 |
|---|---|
| **色差故障**（chromatic aberration） | 标题或图片边缘的 RGB 错位 |
| **扫描线 / 颗粒** | scanline + film grain |
| **故障切片** | glitch displacement，横向切断几行 |
| **描边字 / 镂空字** | outlined / stencil 标题变体 |
| **竖向排字** | 局部文字转 90° |

### 严禁

```
圆角 · 投影 · 柔和渐变 · 紫色/霓虹消费级配色
等距规整的卡片网格 · 全部正放 · 无层次的纯平背景
"干净现代 SaaS 风" · 通用模板感
```

## 三、色彩纪律（关键修正）

**外壳层**：纸白 + 碳黑 + **单一强调色（酸性黄）**
**内容层**：**必须放开**，允许且鼓励高饱和撞色

| 色 | 值 | 用法 |
|---|---|---|
| 酸性荧光黄 | `#E8FF00` | **大面积色块 + 宽斜带**（不是小点缀） |
| 电光蓝 | `#1E3AFF` | **大面积形状 + 通栏色带** |
| 洋红警示粉 | `#FF2B8A` | 小面积警报（贴纸、圆标） |
| 碳黑 / 纸白 | `#0D0D0D` / `#F7F7F5` | 结构与基底 |
| CMYK 套准色 | `#00AEEF` `#EC008C` `#FFF200` `#000` | 边距小方块 |

> ⚠️ 之前我只用小色块（黄/蓝/橙各一个方块），这是**弱化而非克制**。
> 真正的酸性设计特征是**大面积高饱和色块的暴力碰撞**。

## 四、两层结构的分工（务必分清）

```
┌─ 外壳层（克制）────────────────────┐
│  顶栏 · 导航 · 区块标题 · 页脚        │
│  纸白底 + 黑色结构 + 黄作为唯一强调    │
├─ 内容层（狂野）────────────────────┤
│  作品图 · 留言卡 · 文章插图 · 装饰带   │
│  斜切 · 拼贴 · 撞色 · 网点 · 套准标记  │
└─────────────────────────────────────┘
```

**分界不是"哪些页面"，而是"哪些元素"**：
导航可以克制，但同一页的作品图区必须狂野。
一个页面上两者并存，才是这套风格的正确形态。

## 四之二、强度档位（2026-09 修订）

第一版过于保守（像干净模板），第二版又**用力过猛**（堆满元素，变成视觉噪音）。
正确档位在两者之间：**风格元素齐全，但每页只用其中 2–3 个，且不铺满。**

### 用量上限（硬约束）

| 元素 | 每页上限 |
|---|---|
| 实心色块（黄/蓝） | **1–2 处**，且必须让开图片焦点 |
| 斜向色带 | **1–2 道**（不是满页交叉） |
| 幽灵描边字/数字 | **最多 1 个**，且只局部 |
| 网点纹理 | **最多 1 处局部**，不铺满背景 |
| 贴纸标签 | **1–2 个** |
| CMYK 套准标记 + 条形码 | 保留（小、在边距，不抢戏） |
| 旋转/错位 | **少数元素**，主体保持正交 |
| **1px 结构细线** | **必须保留** —— 这是瑞士骨架，不是"黑线太多" |

### 关键区分

用户说"黑线太多"指的是**密密麻麻切满格子的黑线**，
不是**作为结构分区的那几条 1px 灰线**。后者是骨架，不能删。

同理，"别太单调"指的是**缺少色块与斜带的冲击**，
不是**缺少满页贴纸和网点**。

### 正确的平衡（参考 `homepage_reference.png`）

```
色块  → 压在图片上、边缘溢出，但图片主体仍清晰可见
斜带  → 1–2 道，方向明确
幽灵字 → 几乎没有，或极淡
网点  → 局部（图片一角）
贴纸  → 0–1 个
结构  → 1px 细线清晰分区，信息层级靠线不靠色
```

> **总判据修订**：
> 不是"越花越对"，而是 ——
> **一页里有 2–3 个明确的视觉爆点，其余部分安静有序。**

## 五、每次出图后的自检清单

出图后逐条核对，任一为否则重出：

```
□ 有斜向色带吗？是否只有 1–2 道、方向明确？
□ 有实心色块吗？是否只有 1–2 处、且让开了图片焦点？
□ 有 CMYK 套准标记或条形码吗？（边距小元素，保留）
□ 贴纸是否控制在 1–2 个以内？
□ 网点/幽灵字是否只局部出现，没有铺满？
□ 主体是否基本正交？（旋转只用在少数元素）
□ 有 1px 结构细线分区吗？（骨架，必须有）
□ 整页看过去，是否只有 2–3 个视觉爆点，其余安静？
□ 整体像"印刷海报/zine"还是"干净网页模板"？
```

**总判据**：像印刷海报 / zine 就对；像干净模板是退化，像塞满贴纸的噪音墙也是退化。
**正确形态**：有明确的视觉爆点，但页面仍然读得下去。

## 六、对开发的约束

这套纪律不只约束出图，也约束前端实现：

- 斜向色带 → CSS `transform: rotate()` + `clip-path`，允许溢出 `overflow: hidden` 裁切
- 贴纸 → 绝对定位 + 可旋转，`mix-blend-mode` 可选
- 网点 / 扫描线 → SVG pattern 或 `repeating-linear-gradient`
- 套准标记 / 条形码 → 内联 SVG 组件
- 幽灵数字 → 绝对定位 + `-webkit-text-stroke`
- **不允许**为了"好实现"而简化成规整卡片网格
