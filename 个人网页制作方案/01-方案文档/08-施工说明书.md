### 空状态设计
项目未完成时**不编写替代内容**，用排版化空状态诚实呈现：

```
┌──────────────────────────────────────┐
│ 01 PROJECT                           │
│                                      │
│ 知 遇                                │  ← 大号等宽/黑体项目名
│ ZHIYU                                │
│                                      │
│ 在你认识一个人之前，让 Agent 先认识 TA  │  ← GitHub 简介原文
│                                      │
│ ────────────────────────────────     │
│ TYPE      AI AGENT / FULL-STACK      │
│ STATUS    IN PROGRESS                │  ← 如实标注
│ SOURCE    GITHUB ↗                   │
└──────────────────────────────────────┘
```

**设计要点**：
- 用**大字排印**填满栏目，而不是留一片空白
- `STATUS / IN PROGRESS` 如实标注项目状态
- 视觉上与默认图（白底虚线线稿）语义一致 —— 都是"等待填充"
- **不造假内容**：宁可用排版撑场，也不编造项目描述

## 四、视觉规范

### 色彩（修正版）
参考图中黄与蓝是**并用**关系，不是"唯一强调色"。

| 色 | 角色 | 用法 |
|---|---|---|
| 酸性荧光黄 `#E8FF00` | **主强调** | 芯片、高亮、当前项、斜带 —— 每页 1–2 处 |
| 电光蓝 `#1E3AFF` | **大色块** | 通栏带、大形状 —— 每页 1 处 |
| 碳黑 `#0D0D0D` | 结构与文字 | 巨字、1px 细线 |
| 纸白 `#F9F9F9` | 基底 | 全站背景 |
| 洋红 `#FF2B8A` / 橙红 `#FF4422` | 小警报 | 点缀 |

### 字体
| 用途 | 字族 | 状态 |
|---|---|---|
| 展示级标题 | **Archivo Black** | 需自托管 woff2（约 100KB） |
| 正文 / 界面 | Outfit | 可用 Google Fonts 或自托管 |
| 元数据 / 编号 | JetBrains Mono | 需引入 |
| 中文 | 思源黑体 Heavy + 思源宋体 | 需引入 |

### 铁律
1. **零圆角、无阴影、无柔和渐变**
2. **每页只有 2–3 个视觉爆点**，其余安静有序
3. **1px 结构细线是骨架，必须保留**
4. **内容层放开撞色，外壳层克制**
5. **动效禁用回弹** —— 统一 `cubic-bezier(0.22, 1, 0.36, 1)`

详见 `04-视觉纪律.md`。

## 五、功能规格

### 留言墙

### 音乐播放器 ★ 已按作者样例图定稿
**播放器是全站唯一允许「圆角 + 玻璃拟态」的组件**，其余一切仍为零圆角。

| 项 | 规格 |
|---|---|
| 三态 | 折叠（54×117 竖玻璃标签）→ 主屏（500×285）→ 歌单（500×660） |
| 位置 | **固定屏幕右下角** |
| 主屏结构 | 左栏（曲名/艺术家/专辑）+ **中央黑胶** + 右栏（时间/模式/歌词）+ 两行控制 |
| **黑胶** | 圆形，中央贴专辑封面；**播放时旋转、暂停停住**；无封面则不显示 |
| 高亮色 | **酸性黄 `#E8FF00`**（改自样例图的绿色） |
| 歌单 | **不重复显示黑胶**；顶部**搜索框**（即时过滤）；当前曲整行高亮 |
| 播放模式 | **三态单按钮**：顺序 → 单曲循环 → 随机 |
| 收起 | **点面板外部关闭** |
| 默认音量 | **40%**，不自动播放 |
| 持久化 | 音量 / 当前曲 / 模式 / 播放进度 |
| 规模 | **100+ 首** → 需**虚拟滚动** |
| 移动端 | 面板宽度 `calc(100vw - 32px)`，拉宽至接近满宽 |
| 技术 | 原生 `<audio>`，不引第三方播放器库 |

详见 `05-播放器规格.md`（已按样例图重写）。

### 处理决定

| 插画头像与站点冷峻风格冲突 | **保持原图** —— 不做灰度、不做双色调处理 |
