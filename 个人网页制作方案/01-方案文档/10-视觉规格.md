# 视觉规格

> 字体排印、图片处理、响应式断点的完整规格。
> 与 `08-施工说明书.md` 配合使用。

---

## 一、字体排印

### 1.1 字族与分工 ★

采用**混合方案**：界面等宽，长文无衬线。

| 用途 | 字族 | 回退栈 |
|---|---|---|
| **展示级标题** | **Archivo Black** | `'Archivo Black', 'Noto Sans SC', sans-serif` |
| **正文 / 长文** | **Inter** | `'Inter', 'Noto Sans SC', -apple-system, sans-serif` |
| **界面 / 元数据 / 导航** | **JetBrains Mono** | `'JetBrains Mono', ui-monospace, monospace` |
| **中文（标题）** | **思源黑体 Heavy** | 与 Archivo Black 混排 |
| **中文（正文）** | **思源黑体 Regular** | 与 Inter 混排 |

> **为什么这样分**：界面元数据用等宽 → 建立"工程终端"气质；
> 长文用无衬线 → 保证可读性。两者混用是本设计体系的特征。

### 1.2 哪个元素用哪个字体

```
Archivo Black（展示）
  启动页姓名 · 首页姓名 · 区块大标题 · 卡片标题

Inter（正文）
  文章正文 · 笔记正文 · 关于页长文 · 项目 README 渲染 · 留言内容

JetBrains Mono（界面）
  顶部导航 · 编号 · 坐标 · 时间戳 · 按钮文字 · 芯片标签
  元数据表 · 卡片副信息 · 页脚 · 播放器所有文字 · 留言署名行
```

### 1.3 完整字阶

**展示级 · Archivo Black · 全大写 · 字距 `-0.04em` · 行高 `0.86`**

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--fs-d0` | `clamp(3rem, 12vw, 16rem)` | 启动页姓名 |
| `--fs-d1` | `clamp(2.5rem, 8vw, 10rem)` | 首页姓名 |
| `--fs-d2` | `clamp(2rem, 5vw, 6rem)` | 区块大标题 |
| `--fs-d3` | `clamp(1.5rem, 3vw, 3rem)` | 卡片标题 |

**正文级 · Inter · 行高 `1.65` · 字距 `0`**

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--fs-b1` | `clamp(15px, 1.1vw, 17px)` | 段落 |
| `--fs-b2` | `14px` | 次级说明 |
| `--fs-b3` | `13px` | 卡片描述 |

**数据级 · JetBrains Mono · 全大写 · 字距 `+0.08em` · 行高 `1.3`**

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--fs-m1` | `14px` | 导航、主要标签 |
| `--fs-m2` | `12px` | 元数据、编号 |
| `--fs-m3` | `10px` | 版权、微小注记 |

**巨型数字 · Mono · 兼作装饰**

| 令牌 | 字号 |
|---|---|
| `--fs-n1` | `clamp(2.5rem, 5vw, 5rem)` |

### 1.4 中英混排处理

| 场景 | 处理 |
|---|---|
| **中文巨字标题** | 思源黑体 Heavy，**不做逐字拆分**（整行上推） |
| **中英混排标题** | 英文用 Archivo Black，中文用思源黑体 Heavy，**基线与高度对齐** |
| **中文正文** | 思源黑体 Regular，行高提到 `1.8`（比英文更松） |
| **全角标点** | 使用中文标点，不加额外字距 |

> ⚠️ **中文字距铁律**：巨型中文标题**绝不能用等宽字**，也**不能做负字距**（会粘连）。
> 中文巨字的紧凑感靠**思源黑体 Heavy 本身的字重**与**压缩行高**实现。

## 二、图片处理规范

### 2.1 各类型处理

| 图片类型 | 处理 | hover |
|---|---|---|
| 项目截图 | `grayscale(0.9) contrast(1.05)` | 恢复原色，400ms |
| 文章封面 | `grayscale(1)` | 恢复原色，400ms |
| 关于页肖像 | **保持原色** | 不变 |
| 默认线稿图 | **保持原样** | 不变 |
| 黑胶盘面 | **保持原色** | 不变 |
| 留言头像 | 无（不显示头像） | — |

### 2.2 撞色块叠加 ★

采用**半透明色块**（70% 不透明度），能看见底下的图。

```css
.color-block {
  background: var(--accent);
  opacity: 0.7;
  /* 硬边、零圆角、无混合模式 */
}
```

| 项 | 规格 |
|---|---|
| 不透明度 | **70%** |
| 形状 | 实心矩形或斜条，硬边 |
| 圆角 | 0 |
| 位置 | 压住图片一角或斜穿，**避开焦点区域** |
| 每页用量 | 1–2 处（见 `04-视觉纪律.md`） |

### 2.3 宽高比

| 位置 | 比例 |
|---|---|
| 作品卡缩略图 | **16:10** |
| 作品详情大图 | 保留原始比例，最大高度 `90vh` |
| 文章封面 | **16:9** |
| 关于页肖像 | **1:1**（头像是正方形） |
| 黑胶盘面 | **1:1** |

### 2.4 加载策略

| 项 | 规格 |
|---|---|
| 格式 | WebP 优先，`<picture>` 回退 |
| 懒加载 | `loading="lazy"`（首屏主视觉除外） |
| 尺寸 | 按容器宽度生成 2 倍图（`srcset`） |
| 占位 | 骨架屏（浅灰 `#E6E5E1` + 黄块闪烁） |
| 失败回退 | 显示 `default-cover.png` |
| 扫描线 | 极淡水平线叠加；hover 时一条亮线自上而下扫过（600ms） |

### 2.5 处理后端

Next.js `next/image` 处理尺寸与格式转换。
**注意**：`Zhihu_ZhiYu` 仓库体积 92.8 MB，抓取其截图时需限制尺寸。

## 三、响应式断点

### 3.1 断点表

| 令牌 | 宽度 | 容器 | 栅格 |
|---|---|---|---|
| `sm` | `< 640px` | 100% - 32px | 4 栏 |
| `md` | `640–1024px` | 100% - 48px | 8 栏 |
| `lg` | `1024–1440px` | 100% - 64px | 16 栏 |
| `xl` | `1440–1920px` | 1440px | 16 栏 |
| `2xl` | `> 1920px` | 1680px | 16 栏 |

### 3.2 首页首屏

```
lg+    ┌──────┬────────┬──────┐
       │姓名  │ 主视觉  │信息卡 │
       │ 5/16 │  6/16  │ 5/16 │
       └──────┴────────┴──────┘

md     ┌──────────────────────┐
       │      姓名通栏         │
       ├──────────────────────┤
       │      主视觉通栏        │
       ├──────────────────────┤
       │   信息卡通栏（四行）    │
       └──────────────────────┘

sm     同 md，字号降档、间距收紧
```

### 3.3 作品区

| 断点 | 列数 |
|---|---|
| `lg+` | 4 列 |
| `md` | 2 列 × 2 行 |
| `sm` | 1 列 |

### 3.4 导航 ★

| 断点 | 表现 |
|---|---|
| `lg+` | `01 WORK` `02 ARTICLES` `03 NOTES` `04 ABOUT` 横排 |
| `md` | 同上，字号降到 `--fs-m2` |
| **`sm`** | **只留编号** `01` `02` `03` `04`，**标签文字隐藏** |

手机端导航 HTML 结构（无障碍友好）：
```html
<a href="/work" aria-label="WORK">
  <span class="num">01</span>
  <span class="label">WORK</span>   <!-- 手机上 display: none -->
</a>
```
> `aria-label` 保留语义，屏幕阅读器仍能读出「WORK」。

### 3.5 播放器

| 断点 | 尺寸 |
|---|---|
| 桌面 | 主屏 `500×285`，歌单 `500×660` |
| 手机 | 宽度 `calc(100vw - 32px)`，歌单占满屏高 |

### 3.6 其他页面

| 页面 | md | sm |
|---|---|---|
| 作品详情（左栏+右栏） | 左栏上移通栏，右栏在下 | 单列 |
| 文章阅读（窄栏居中） | 栏宽放宽到 80% | 栏宽 100% - 32px |
| 笔记详情（卡片+侧栏） | 侧栏移到下方 | 单列 |
| 关于页（左右分栏） | 纵向堆叠 | 单列 |
| 留言墙（3 列卡片） | 2 列 | 1 列 |
| 编辑器（正文+侧栏） | 侧栏移到下方 | 单列 |

### 3.7 触屏适配

| 项 | 处理 |
|---|---|
| **鼠标坐标层** | **触屏设备不启用** |
| hover 效果 | 触屏改用 `:active`，或改为点击触发 |
| 触摸目标 | 最小 `44×44px` |
| 横屏 | 播放器面板高度自适应，不遮挡内容 |

## 四、间距系统

**基准单位 `8px`**，所有间距取 8 的倍数。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sp-1` | `8px` | 紧凑元素间 |
| `--sp-2` | `16px` | 元数据行距 |
| `--sp-3` | `24px` | 卡片内间距 |
| `--sp-4` | `32px` | 区块内间距 |
| `--sp-6` | `48px` | 区块间距 |
| `--sp-8` | `64px` | 大区块间距 |
| `--sp-12` | `96px` | 页面级留白 |
| `--sp-16` | `128px` | 首屏留白 |

## 五、1px 线系统

**这是骨架，必须保留**（见 `04-视觉纪律.md`）。

| 类型 | 规格 |
|---|---|
| 结构分隔线 | `1px solid #0D0D0D`（横向贯穿） |
| 细分隔线 | `1px solid rgba(13,13,13,0.12)` |
| 栅格线 | 由 `display: grid; gap: 1px` + 父子异色背景生成 |
| 虚线 | `1px dashed`（用于输入框、拖拽区） |
| 焦点描边 | `2px solid #0D0D0D`，深色底改酸性黄 |

## 六、决策速查

| 组 | 问题 | 决定 |
|---|---|---|
| T1 | 正文字体 | **混合**：界面等宽（JetBrains Mono），长文无衬线（Inter） |
| T2 | 撞色块叠加 | **半透明 70%** |
| T3 | 手机导航 | **只留编号**，标签隐藏（保留 `aria-label`） |
