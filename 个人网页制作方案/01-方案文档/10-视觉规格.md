> 字体排印、图片处理、响应式断点的完整规格。
> 与 `08-施工说明书.md` 配合使用。

## 一、字体排印

### 1.1 字族与分工 ★

采用**混合方案**：界面等宽，长文无衬线。

| 用途 | 字族 | 回退栈 |
|---|---|---|
| **展示级标题** | **Archivo Black** | `'Archivo Black', 'Noto Sans SC', sans-serif` |
| **正文 / 长文** | **Inter** | `'Inter', 'Noto Sans SC', -apple-system, sans-serif` |
| **界面 / 元数据 / 导航** | **JetBrains Mono** | `'JetBrains Mono', ui-monospace, monospace` |
| **中文（标题）** | **思源黑体 Heavy** | 与 Archivo Black 混排 |
| **中文（正文）** | **思源黑体 Regular** | 与 Inter 混排 |

> **为什么这样分**：界面元数据用等宽 → 建立"工程终端"气质；
> 长文用无衬线 → 保证可读性。两者混用是本设计体系的特征。

### 1.2 哪个元素用哪个字体

```
Archivo Black（展示）
  启动页姓名 · 首页姓名 · 区块大标题 · 卡片标题

Inter（正文）
  文章正文 · 笔记正文 · 关于页长文 · 项目 README 渲染 · 留言内容

JetBrains Mono（界面）
  顶部导航 · 编号 · 坐标 · 时间戳 · 按钮文字 · 芯片标签
  元数据表 · 卡片副信息 · 页脚 · 播放器所有文字 · 留言署名行
```

### 1.3 完整字阶

**展示级 · Archivo Black · 全大写 · 字距 `-0.04em` · 行高 `0.86`**

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--fs-d0` | `clamp(3rem, 12vw, 16rem)` | 启动页姓名 |
| `--fs-d1` | `clamp(2.5rem, 8vw, 10rem)` | 首页姓名 |
| `--fs-d2` | `clamp(2rem, 5vw, 6rem)` | 区块大标题 |
| `--fs-d3` | `clamp(1.5rem, 3vw, 3rem)` | 卡片标题 |

**正文级 · Inter · 行高 `1.65` · 字距 `0`**

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--fs-b1` | `clamp(15px, 1.1vw, 17px)` | 段落 |
| `--fs-b2` | `14px` | 次级说明 |
| `--fs-b3` | `13px` | 卡片描述 |

**数据级 · JetBrains Mono · 全大写 · 字距 `+0.08em` · 行高 `1.3`**

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--fs-m1` | `14px` | 导航、主要标签 |
| `--fs-m2` | `12px` | 元数据、编号 |
| `--fs-m3` | `10px` | 版权、微小注记 |

**巨型数字 · Mono · 兼作装饰**

| 令牌 | 字号 |
|---|---|
| `--fs-n1` | `clamp(2.5rem, 5vw, 5rem)` |

### 1.4 中英混排处理

| 场景 | 处理 |
|---|---|
| **中文巨字标题** | 思源黑体 Heavy，**不做逐字拆分**（整行上推） |
| **中英混排标题** | 英文用 Archivo Black，中文用思源黑体 Heavy，**基线与高度对齐** |
| **中文正文** | 思源黑体 Regular，行高提到 `1.8`（比英文更松） |
| **全角标点** | 使用中文标点，不加额外字距 |

> ⚠️ **中文字距铁律**：巨型中文标题**绝不能用等宽字**，也**不能做负字距**（会粘连）。
> 中文巨字的紧凑感靠**思源黑体 Heavy 本身的字重**与**压缩行高**实现。

## 二、图片处理规范

### 2.1 各类型处理 ★（2026-09-13 修正）

> **修正原因**：旧规格规定「项目截图去饱和 `grayscale(0.9)`」，
> 与当前设计稿（`gpt-image-2.5` 全套）不符 —— 设计稿里的图片是**彩色厚涂插画**。
> 作者确认：**项目图保持彩色**。

| 图片类型 | 处理 | hover |
|---|---|---|
| **项目截图 / 作品图** | **保持原色**（不做灰度） | 轻微放大 `scale(1.02)`，400ms |
| **首页主视觉** | **保持原色** | 无（配粒子和视差，见 §2.6） |
| 文章封面 | 保持原色 | 轻微放大 `scale(1.02)` |
| 关于页肖像 | **保持原色** | 不变 |
| 默认线稿图 | **保持原样** | 不变 |
| 黑胶盘面 | **保持原色** | 不变 |

**色彩统一靠什么**：不靠去饱和，靠**黄蓝色块叠加 + 统一的图表化构图 + 一致的边框与元数据**。

> ⚠️ 旧的「去饱和图 + 直角色块」公式**已作废**（见 `04-视觉纪律.md` 修订）。

### 2.2 撞色块叠加 ★

采用**半透明色块**（70% 不透明度），能看见底下的图。

```css
.color-block {
  background: var(--accent);
  opacity: 0.7;
  /* 硬边、零圆角、无混合模式 */
}
```

| 项 | 规格 |
|---|---|
| 不透明度 | **70%** |
| 形状 | 实心矩形或斜条，硬边 |
| 圆角 | 0 |
| 位置 | 压住图片一角或斜穿，**避开焦点区域** |
| 每页用量 | 1–2 处（见 `04-视觉纪律.md`） |

### 2.3 宽高比

| 位置 | 比例 |
|---|---|
| 作品卡缩略图 | **16:10** |
| 作品详情大图 | 保留原始比例，最大高度 `90vh` |
| 文章封面 | **16:9** |
| 关于页肖像 | **1:1**（头像是正方形） |
| 黑胶盘面 | **1:1** |

### 2.4 加载策略

| 项 | 规格 |
|---|---|
| 格式 | WebP 优先，`<picture>` 回退 |
| 懒加载 | `loading="lazy"`（首屏主视觉除外） |
| 尺寸 | 按容器宽度生成 2 倍图（`srcset`） |
| 占位 | 骨架屏（浅灰 `#E6E5E1` + 黄块闪烁） |
| 失败回退 | 显示 `default-cover.png` |
| 扫描线 | 极淡水平线叠加；hover 时一条亮线自上而下扫过（600ms） |

### 2.5 处理后端

Next.js `next/image` 处理尺寸与格式转换。
**注意**：`Zhihu_ZhiYu` 仓库体积 92.8 MB，抓取其截图时需限制尺寸。

### 2.5.1 GitHub README 封面图优化 ★

**实测问题**：从 README 抓到的首图**分辨率过大**，不能直接塞进卡片。

| 仓库 | 原图尺寸 | 大小 |
|---|---|---|
| `Intelligent-Service-Assistant` | **2559 × 1348** | 673 KB |
| `Dagou_Game` | **2559 × 1399** | 161 KB |

**处理要求**：
```
必须用 next/image 的 remotePatterns 允许 raw.githubusercontent.com
按容器宽度生成 1x/2x 响应式图
自动转 WebP
卡片缩略图目标体积 < 150 KB
```

`next.config.ts` 需要配置：
```ts
images: {
  remotePatterns: [
    { protocol: 'https', hostname: 'raw.githubusercontent.com' },
    { protocol: 'https', hostname: 'avatars.githubusercontent.com' },
  ],
}
```

### 2.6 首页主视觉 ★（2026-09-13 新增）

> **已取消轮播**。作者决定：**单张静态图 + 动效**。

```
┌──────────────────────────────────────┐
│  巨字问候 + 中文主张 + 黄色方形按钮      │
│                                      │
│         ┌──────────────────┐         │
│         │   单张静态主视觉   │         │
│         │   （厚涂插画）     │         │
│         │  + 漂浮粒子层      │         │
│         │  + 鼠标视差位移    │         │
│         └──────────────────┘         │
└──────────────────────────────────────┘
```

**图片要求**：
- 单张，**保持原色**，不做灰度
- 无轮播、无 `01 / 05` 计数
- 内容：厚涂插画风格（人物 + 黄蓝色块 + 灰色建筑背景）

**素材已定** ★（2026-09-13）

```
首页主视觉 = 04-素材/主视觉/主视觉-03-宽幅.png
             1536 × 1024，纸白底，无透明通道
```

| 文件 | 尺寸 | 状态 |
|---|---|---|
| `主视觉-01-横向.png` | 1536×1024 | 弃用 |
| `主视觉-02-紧凑.png` | 1254×1254 | **保留备用**（分享卡片 / 关于页等方形场景） |
| **`主视觉-03-宽幅.png`** | 1536×1024 | ★ **采用** |

**采用 03 的理由**：留白最多（符合用量纪律）· 含斜向黄带（体系核心元素）· 构图弹性最好（元素集中、四周空白，便于按屏宽裁切）。

> ⚠️ **无透明通道**，底色为纸白 `#F9F9F9`。
> 页面底色同为纸白，**直接使用无边界问题**；
> 若将来需叠在非纸白背景上，需另行抠图或生成带 alpha 的版本。

**实现要点**：
- 用 `next/image`，`priority` 预加载（首屏关键图）
- 按屏宽裁切时**保持人物与黄圆不被切到**，优先裁两侧空白
- 尺寸变体：桌面 1536×1024 原图可用；移动端裁成 4:5 或 1:1 竖版

**动效规格**见 `09-动效与交互规格.md` §5.4（漂浮粒子 + 鼠标排斥 + 视差位移）。

## 三、响应式断点

### 3.1 断点表

| 令牌 | 宽度 | 容器 | 栅格 |
|---|---|---|---|
| `sm` | `< 640px` | 100% - 32px | 4 栏 |
| `md` | `640–1024px` | 100% - 48px | 8 栏 |
| `lg` | `1024–1440px` | 100% - 64px | 16 栏 |
| `xl` | `1440–1920px` | 1440px | 16 栏 |
| `2xl` | `> 1920px` | 1680px | 16 栏 |

### 3.2 全站布局骨架

```
lg+    ┌────┬──────────────────────────────────────┐
       │    │  顶栏 搜索·偏好·邮箱·菜单              │
       │ 竖 ├──────────────────────────────────────┤
       │ 栏 │  主内容区                             │
       │140 │                                       │
       │ px │                                       │
       └────┴──────────────────────────────────────┘

md     竖栏收窄至 56px（只显示图标，文字隐藏）

sm     竖栏消失，收进顶栏菜单图标，点击弹出全屏导航
```

> 竖栏**固定定位**，不参与滚动；主内容区左侧留出竖栏宽度。
> 详见 §3.4（竖栏规格）与 §3.5（首页布局）。

### 3.4 左侧竖栏导航 ★（本轮改版）

> 旧方案是顶部横排四项。**新设计稿改为左侧固定竖栏六项。**

**桌面（`lg+`）**
```
宽度        140px 固定，不随内容变化
排布        固定定位（position: fixed），不参与滚动
结构        品牌区（顶部，可点进关于页）
            ────────
            六项导航，每项：图标 + 中文（上）/ 极小英文（下）
            ────────
            底部装饰标记
高度        100vh，内部不滚动
```

**单项尺寸**
```
图标      20×20
中文      14px  JetBrains Mono 或思源黑体 Medium
英文      9px   JetBrains Mono，字距 +0.08em，颜色 60% 黑
行距      中文与英文之间 2px
项间距    20px
当前项    左侧一条 3px 酸性黄竖条 + 中文变黑体加粗
```

**各断点表现**

| 断点 | 表现 |
|---|---|
| `lg+` | 左侧固定竖栏 140px，主内容区左侧留出 140px |
| `md` | 竖栏收窄至 **56px**，只显示图标，文字隐藏（悬停出提示） |
| **`sm`** | 竖栏**收进顶栏菜单**，点击菜单图标弹出全屏导航 |

**无障碍结构**（文字被隐藏时仍保留语义）：
```html
<nav aria-label="主导航">
  <a href="/work" aria-label="作品集 WORKS">
    <svg class="icon" aria-hidden="true">…</svg>
    <span class="zh">作品集</span>
    <span class="en">WORKS</span>
  </a>
</nav>
```

### 3.5 首页布局 ★（本轮改版）

```
lg+    ┌────┬──────────────────────────┬────────────┐
       │    │  顶栏                     │            │
       │ 竖 ├──────────────────────────┤  右栏三块   │
       │ 栏 │  主视觉（巨字+插画+粒子）   │  ① 播放器   │
       │    ├──────────────────────────┤  ② 留言入口 │
       │140 │  FEATURED WORKS 四张卡     │  ③ 暗色卡   │
       │ px ├───────────┬──────────────┤            │
       │    │ NOTES 2条 │ ARTICLES 3条 │            │
       └────┴───────────┴──────────────┴────────────┘

md     竖栏收至 56px（只图标）
       右栏三块移到主内容下方，横向排列或堆叠

sm     竖栏收进顶栏菜单
       所有区块单列纵向堆叠
```

### 3.6 作品卡

| 断点 | 列数 |
|---|---|
| `lg+` | 4 列（首页）／ 3 列（作品集页） |
| `md` | 2 列 |
| `sm` | 1 列 |

### 3.7 播放器

| 断点 | 尺寸 |
|---|---|
| 桌面 | 主屏 `500×285`，歌单 `500×660` |
| 手机 | 宽度 `calc(100vw - 32px)`，歌单占满屏高 |

### 3.8 其他页面

| 页面 | md | sm |
|---|---|---|
| 作品详情（左栏+右栏） | 左栏上移通栏，右栏在下 | 单列 |
| 文章阅读（窄栏居中） | 栏宽放宽到 80% | 栏宽 100% - 32px |
| 笔记详情（卡片+侧栏） | 侧栏移到下方 | 单列 |
| 关于页（左右分栏） | 纵向堆叠 | 单列 |
| 留言墙（3 列卡片） | 2 列 | 1 列 |
| 编辑器（正文+侧栏） | 侧栏移到下方 | 单列 |

### 3.7 触屏适配

| 项 | 处理 |
|---|---|
| **鼠标坐标层** | **触屏设备不启用** |
| hover 效果 | 触屏改用 `:active`，或改为点击触发 |
| 触摸目标 | 最小 `44×44px` |
| 横屏 | 播放器面板高度自适应，不遮挡内容 |

## 四、间距系统

**基准单位 `8px`**，所有间距取 8 的倍数。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sp-1` | `8px` | 紧凑元素间 |
| `--sp-2` | `16px` | 元数据行距 |
| `--sp-3` | `24px` | 卡片内间距 |
| `--sp-4` | `32px` | 区块内间距 |
| `--sp-6` | `48px` | 区块间距 |
| `--sp-8` | `64px` | 大区块间距 |
| `--sp-12` | `96px` | 页面级留白 |
| `--sp-16` | `128px` | 首屏留白 |

## 五、1px 线系统

**这是骨架，必须保留**（见 `04-视觉纪律.md`）。

| 类型 | 规格 |
|---|---|
| 结构分隔线 | `1px solid #0D0D0D`（横向贯穿） |
| 细分隔线 | `1px solid rgba(13,13,13,0.12)` |
| 栅格线 | 由 `display: grid; gap: 1px` + 父子异色背景生成 |
| 虚线 | `1px dashed`（用于输入框、拖拽区） |
| 焦点描边 | `2px solid #0D0D0D`，深色底改酸性黄 |

## 七、本轮改版要点（2026-09-12）

设计稿更换为 `gpt-image-2.5` 全套 15 张后，本文件相应更新：

| 章节 | 变更 |
|---|---|
| §3.2 布局骨架 | 旧「顶部横排导航」→ **左侧固定竖栏** |
