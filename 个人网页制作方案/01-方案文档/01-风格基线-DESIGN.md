## 1. 视觉主题与氛围

**一句话定位**：*Swiss 编辑排版骨架 + 解构主义拼贴肌理 + HUD 技术元数据语法*。

两种艺术主义在同一条脉络上叠加：

- **基底：瑞士国际主义排版**（Swiss / International Typographic Style）
  巨型无衬线标题、严格栅格、左对齐、零圆角、信息层级靠字重与字号而非颜色。
- **冲击层：解构主义 / 酸性平面**（Deconstruction / Acid Graphics）
  斜向色带切穿画面、元素旋转错位、拼贴重叠、荧光色暴力撞击、贴纸与印章覆盖。
- **秩序层：HUD / 战术遥测语法**
  编号 `01–06`、等宽字元数据、十字定位标记 `+`、坐标 `31.2304°N, 121.4737°E`、`REV`/`SPEED #2`/`FRAME` 类伪技术标签。

**氛围**：冷峻、工程化、带印刷颗粒的"技术档案"感，而非消费级产品的柔和感。

### 2.2 两条色彩策略（用户已识别，我确认成立）

- **A 组 狂野/拼贴**：黑白灰基底上叠加 2–3 个**全饱和原色**，色块**大面积极端**、边缘**硬直**、允许互相**重叠切割**。
- **B 组 克制/HUD**：灰白空间 + 单一荧光黄作唯一焦点，黑负责结构，灰负责填充。**强调色面积占比极低**。

> **关键观察**：全部 4 张首页稿都走 **B 组**；`jumpover2` 与作品图走 **A 组**。
> 即：**站点外壳克制（B），作品内容狂野（A）**。这是一个可用的分工，不是矛盾。

## 3. 字体排印

### 3.1 宏观（结构标题）
- 分类：Neo-Grotesque Heavy / 几何无衬线超粗
- 实测特征：`YOUR NAME` / `JANE DOSE` / `IGNORE DONE.SPACE` / `HERO POEM`
- 参数：字号 `clamp(4rem, 10vw, 15rem)`；字距 `-0.03em ~ -0.06em`；行高 `0.85–0.95`；**全大写**
- 候选字族：Inter Black / Archivo Black / Neue Haas Grotesk / Monument Extended

### 3.2 微观（元数据）
- 分类：等宽 / 技术无衬线
- 实测：`DEVELOPER / DESIGN / THINKING`、`31.2304° N, 121.4737° E`、`04 TOTAL`、`SPEED #2`、`FRAME`
- 参数：`10–14px`；字距 `+0.05em ~ +0.1em`；全大写
- 候选字族：JetBrains Mono / IBM Plex Mono / Space Mono
- **注意**：等宽字对中文支持普遍差，做中文版需另配中文字族

### 3.3 数字与巨型编号
`01`–`06` 贯穿全站，兼作导航前缀与区块序号；`01 / 04` 作轮播计数；`04 TOTAL` / `2026 YEAR` 作巨型统计字。

## 4. 间距与栅格

- **栅格**：首页三栏结构，实测约 `30 / 40 / 30`；作品区为 4 等分列
- **参考系统**：`deck-swiss-international` 的 16 栏模型可直接套用
- **分隔**：大量 `1px` 实线横向贯穿全宽；区块边界靠线不靠间距
- **圆角**：**全站 0 圆角**（首页 4 张稿、作品框、按钮一律直角）
- **阴影**：无。层级靠线框、明度差、面积差建立
- **定位标记**：`+` 十字出现在板块四角或栅格交点
- **密度**：双峰式 —— 巨型标题周围大面积留白 ↔ 元数据密集堆叠

## 5. 布局与构图

### 5.1 首页外壳（4 张稿的共识结构）
1. **顶栏**：Logo 方块 + 双行品牌名 ｜ `01 PROFILE` `02 WORK` `03 NOTES` `04 ARCHIVE`（编号+标签两行） ｜ 右上日期时间 + `● ONLINE` 状态灯 + `+`
2. **首屏三栏**：巨型姓名+标语 ｜ 主视觉图（角落 `01 / 04` 计数） ｜ 信息卡堆叠（ABOUT / PROJECTS / CURRENTLY / CONTACT）
3. **作品区**：`06 SELECTED WORKS` + `VIEW ALL →`，4 列卡片，卡下 `序号 + 名称 + 分类 + 年份`
4. **边缘装饰**：右侧竖排 `SCROLL` + `↕`；左下 `//` 斜杠；左侧斜切灰块

### 5.2 构图手法（从参考稿提取）
| 手法 | 证据 |
|---|---|
| 斜向色带切穿画面 | homepage v1 黄色斜带穿主视觉；jumpover2 蓝黄竖带贯穿全身 |
| 旋转/错位 | jumpover2 主视觉整体旋转；首页稿装饰块倾斜 |
| 角括号裁切标记 `⌐ ¬` | homepage v1 主视觉四角；v2 面板角 |
| 拼贴重叠 + 贴纸 | 188/191 中 `SHUTTER TIME` `HEAVY` `STAY` `CENSORED` `DENIED` 标签层 |
| 窄色带作为视觉动线 | Jumpover2 纵向三色带成为画面脊柱 |
| 图与几何共面 | 作品卡：去饱和照片 + 直角色块叠加 |

### 5.3 两套并置的运作方式
- **外壳**：秩序、留白、单一强调色 → 传达"专业、可读、可信"
- **内容**：解构、撞色、拼贴 → 传达"创造力、实验性、能量"
- 切换点：从首屏进入作品区时，色调由克制转为饱和

## 6. 组件

- **作品卡**：直角矩形 + `1px` 描边；缩略图去饱和；右上角直角色块或斜带；下方元数据行（`01` / `PROJECT NAME` / `WEB / UI` / `2025`）
- **导航项**：两行（上编号 下标签），当前项加下划线
- **信息卡**：`编号 + 标题` ／ `正文` ／ 右侧巨型数字或缩略图，三行结构
- **状态指示**：`● ONLINE` 小圆点 + 等宽文字
- **链接箭头**：细长 `→`，与文字基线对齐
- **角标记**：`+` 十字
- **贴纸/印章**（内容侧专用）：黑底白字胶囊、斜置矩形、条形码
- **ASCII/HUD 装饰**（v2 侧）：`SPEED #2`、`REV`、`FRAME`、`TYPE 02`、条形码

## 7. 动效与交互

参考稿为静帧，以下为 `inferred`：
- **入场**：区块逐个位移淡入，非线性（先快后缓）
- **强调色带**：随滚动做位移或裁切揭示（clip-path）
- **巨型标题**：轻微字距或位置视差
- **箭头**：hover 时水平位移
- **状态灯**：呼吸式透明度循环
- **数字计数**：`01 / 04` 切换时滚动替换
- **原则**：动效服务于"机械精度"感，避免弹性/回弹等柔软缓动

## 8. 语气与品牌

- **文案调性**：短句、全大写、声明式。`BUILD USEFUL THINGS WITH CODE.` / `DESIGN × CODE × CHAOS` / `ESCAPLATOR IS HERE FOR EVERYONE`
- **自我描述关键词**（参考稿实测）：`Developer / Creator`、`Creative technologist`、`Interactive design`
- **伪技术细节**：坐标、版本号、状态、时间戳 —— 用于建立"工程可信度"
- **排版标记**：`®` `©` `™` 兼作几何装饰

---

## 9. 反模式（明确禁止）

- ❌ 圆角、卡片阴影、玻璃拟态、渐变背景
- ❌ 紫蓝渐变、霓虹辉光、现代 SaaS 柔和配色
- ❌ 多强调色并用（外壳层只允许 **1 个**强调色）
- ❌ 中文正文用等宽字（可读性差）
- ❌ 在标题层使用衬线体（仅内容侧可少量、且需做网点/1-bit 处理）
- ❌ 柔软缓动（elastic / bounce）
- ❌ 卡片套卡片套卡片的多层嵌套
- ❌ 把参考稿的**具体文案与品牌标记**照搬（`YOUR NAME` / `JANE DOSE` / `REFINE` 均为占位，不是品牌资产）

## 10. 待决策（阻塞锁定）

**强调色归属冲突**：`industrial-brutalist-ui` skill 规定"**唯一强调色必须是航空红 `#E61919`**"，但你现有的 12 张素材与 `色彩.txt` 都以**酸性荧光黄 `#E8FF00`** 为核心。

两条路：
- **黄主导**（尊重现有素材）→ 需覆盖 skill 的红限制，主体走「酸性荧光黄」
- **红主导**（尊重 skill 规范）→ 需重做全部以黄为主的素材

**我的建议**：**黄主导**。理由：你 12 张素材里 8 张以黄为焦点，改造红版成本高；且 skill 自身也允许"一个项目一套调色板"的自主权，红只是它的默认推荐而非硬性约束。
