# CONCEPT.md — 个人主页构思

> 阶段：**构思，不开发**。本文件记录方向决策与理由，供后续实现时直接执行。
> 上游依据：`DESIGN.md`（12 张参考图分析）、`站点资源地图.md`（ignoredone.space 实测数据）
> 决策状态：`已定` / `待定`（文末列出待你拍板项）

## 0. 一套基因，两层表情

从实测数据得出的核心矛盾：

| 层 | 证据 | 表情 |
|---|---|---|
| **站点外壳** | 首屏 5 黄点+纯黑巨型字+纯白底；4 张首页稿全部克制 | 秩序、留白、单一强调色 |
| **作品内容** | 17 个集合（JUMP OVER / HERO POEM / SPEAK LOUD / DEAD LOOP…）全部高饱和解构拼贴 | 狂野、撞色、拼贴 |

**这不是矛盾，是分工。** 整个站点构思都建立在这条分界线上：
**外壳负责"可信"，内容负责"能量"。** 分界线就在首屏滚入作品区的那一刻。

---

## 1. 艺术主义定型

三种主义叠在一条垂直脉络上，各占一层，**不允许越层**：

| 层 | 主义 | 职责 | 禁止越界 |
|---|---|---|---|
| 骨架 | **瑞士国际主义排版** | 栅格、巨型无衬线、左对齐、零圆角 | 不负责制造情绪 |
| 语法 | **HUD / 战术遥测** | 编号、等宽元数据、十字标记、伪技术标签 | 不负责装饰 |
| 表现 | **解构主义 / 酸性平面** | 斜向色带、旋转错位、拼贴、荧光撞色 | **仅限作品区与内容层** |

> 一句话：**外壳是工程图纸，内容是印刷事故。**
> 反过来说 —— 如果首屏开始拼贴贴纸，这个站就废了；如果作品区变成干净卡片，这个站就平庸了。

## 2. 色彩

### 2.1 角色分配（已定）

| 角色 | 色 | 用量上限 | 出现位置 |
|---|---|---|---|
| **唯一强调色** | 酸性荧光黄 `#E8FF00` | **≤5% 画面面积** | 状态灯 / 链接箭头 hover / 焦点标记 / 1 个整块区块 |
| 基底 | 纸白 `#F7F7F5` | 60–70% | 全站背景 |
| 结构 | 碳黑 `#0D0D0D` | 20–25% | 巨型标题、1px 线、文字 |
| 填充 | 冷灰 `#E6E5E1` `#2B2B2B` | 5–10% | 面板、次级信息 |
| 作品内色 | 蓝 `#1E3AFF` / 橙红 `#FF4422` / 粉 `#FF007A` / 青柠 `#A8D44B` | 无限制 | **仅出现在作品缩略图内部** |

### 2.2 三条铁律

1. **外壳层永远只有 1 个强调色** —— 黄。蓝/橙/粉/绿是**作品的颜色**，不是界面的颜色。它们只能存在于图片像素里，不许溢到边框、按钮、文字上。
2. **红降级**：`industrial-brutalist-ui` skill 要求唯一强调色为航空红 `#E61919`，本案**不采纳**。红只作为 HERO POEM 等作品的自有主色存在。
3. **黄区反转**：只允许**一处**大面积黄 —— 首屏与作品区之间的那条过渡带。它承担"层切换"的叙事功能，是结构元素而非装饰。这次反转之后，全站不再出现第二块黄底。

## 3. 字体

### 3.1 字族决策

| 用途 | 字族 | 理由 | 状态 |
|---|---|---|---|
| **展示级标题** | `Archivo Black` | 900 字重、宽厚、工业感，是 Swiss 骨架的正确表达 | **待补**（你的字体库无此字重） |
| 正文/界面 | `Outfit` | **你站内已自托管**（可变 100–900），几何无衬线，气质吻合 | 已有 |
| 元数据/编号 | `JetBrains Mono` | 等宽、字形硬朗，HUD 语法的基础 | **待补**（库内打字机体风格不符） |
| 中文 | 思源黑体 Heavy + 思源宋体 | 开源可商用 | 待补 |
| ~~中文衬线~~ | ~~京華老宋体 v3.0~~ | ⚠️ **商业字体，需授权**。仅在你已持有授权的场合使用 | 警示 |

> **为什么不自制标题字**：你的库里有打字机体（Another Typewriter / Underwood Champion）和花体（Great Vibes），但它们只适合做作品配图元素，撑不起 `clamp(4rem, 11vw, 15rem)` 的巨型标题。展示级字重必须另找 —— 这是自托管字体之外唯一需要新增的资源。

### 3.2 字阶表

**展示级（全大写，字距 -0.04em，行高 0.86）**
```
D1  clamp(3.5rem, 11vw, 15rem)   ▸ 首屏姓名
D2  clamp(2rem, 5.5vw, 6rem)     ▸ 区块大标题
D3  clamp(1.5rem, 2.5vw, 2.5rem) ▸ 卡片标题
```

**技术级（全大写，字距 +0.08em，行高 1.3）**
```
M1  14px / 500    ▸ 导航、标签
M2  12px / 500    ▸ 元数据、编号、坐标
M3  10px / 400    ▸ 版权、微小注记
```

**正文级**
```
B1  clamp(15px, 1.1vw, 17px)  / 1.65   ▸ 段落
B2  14px / 1.5                          ▸ 次级说明
```

**巨型统计数字（等宽，兼作装饰）**
```
N1  clamp(2.5rem, 4vw, 4.5rem)   ▸ "04 TOTAL" / "2026"
```

## 4. 页面尺寸与栅格

### 4.1 视口策略

| 项 | 值 | 理由 |
|---|---|---|
| 容器上限 | `1680px` | 你的参考稿在 2560 宽下仍保持信息密度，说明它是宽屏设计 |
| 内容最大宽 | `1440px` | 超宽屏两侧留白，避免拉伸 |
| 栅格 | **16 栏**，`gap: 1px` | 用 `gap:1px` + 父子异色背景直接生成发丝分割线，无需 border |
| 左右边距 | `clamp(20px, 4vw, 64px)` | |
| 断点 | `480 / 768 / 1024 / 1440 / 1920` | 1920 以上锁定 1680 容器 |
| 基准行高单位 | `8px` | 所有间距取 8 的倍数 |
| 圆角 | **0** | 全站 |
| 阴影 | **无** | 层级靠线框 + 明度差 + 面积差 |

### 4.2 首屏黄金分割（16 栏）

```
栏位   1────5──────9──────13───16
       │  姓名区  │  主视觉  │ 信息卡 │
       5/16       6/16      5/16
```
- 姓名区：`01 HELLO, I'M` + D1 巨型名 + 一行标语 + `DEVELOPER / DESIGN / THINKING`
- 主视觉：灰度作品图 + 斜向黄色带（唯一允许的装饰）+ 角落 `01 / 04` 计数
- 信息卡：`02 ABOUT` / `03 WORKS` / `04 CURRENTLY` / `05 CONTACT` 四行堆叠，右侧配 N1 巨型数字

### 5.2 六个可复用构图手法（来自参考稿实测）

1. **斜向色带切穿** —— 主视觉上一道黄带，角度约 `-12°`，`overflow: hidden` 裁切
2. **角括号标记** `⌐ ¬` —— 主视觉四角，纯 CSS 伪元素
3. **+ 十字定位** —— 栅格交点，`--marker: #0D0D0D`
4. **去饱和图 + 直角色块叠加** —— 作品卡统一公式：`filter: grayscale(1)` + 绝对定位色块
5. **编号前缀导航** —— `01` 小字 + 标签大字，两行式，当前项加下划线
6. **竖排滚动指示** —— `writing-mode: vertical-rl` + `↕`

## 6. 功能及其分布

### 6.1 页面架构（已定：混合式）

| 页面 | 职责 | 关键功能 |
|---|---|---|
| `/` 首页 | 叙事 + 分流 | 首屏介绍 → 精选 4 件 → 档案入口 → 笔记摘要 → 联系 |
| `/work` | 完整作品档案 | 17 个集合网格；年份 / 类型筛选；hover 预览 |
| `/work/[slug]` | 单件作品 | 图组浏览（`oss/v1/images` 的 `images[]`）、上下篇、元数据表 |
| `/notes` | 教程与随笔 | 文章列表；分类筛选（图标包 / 字体推荐 / 图文教程 / 笔刷） |
| `/notes/[slug]` | 单篇 | 正文 + 代码块 + 图片 |
| `/about` | 关于 | 长文 + 技能 + 时间线 + 装备/工具 |

### 6.2 各页功能明细

**首页**
- 实时时间戳（`2026.09.11 TUE 14:22`，JS 渲染）
- `● ONLINE` 呼吸灯（CSS `animation`，透明度 1→0.35 循环 2.4s）
- `01 / 04` 主视觉轮播（自动 + 手动，横向位移切换）
- 精选作品 hover：灰度 → 原色 + 色块位移
- 全站 `→` 箭头 hover 水平位移（不做弹性缓动）

**档案页**
- 筛选：按年份（2019–2026）/ 按类型（封面 / 字标 / 直播 / 活动）
- 网格密度切换：4 列 / 6 列（HUD 风格的小按钮组）
- **不做无限滚动** —— 用「加载更多」按钮，保持"档案"的克制感

**作品详情页**
- 图组：横向滚动或纵向堆叠，`loading="lazy"`
- 元数据表（`<dl>` 语义化）：年份 / 类型 / 工具 / 尺寸 / 角色
- 图片查看器：点击放大，键盘 `←/→` 切换，无第三方图库依赖

**笔记页**
- 分类筛选 6 类：图标包(6) / 字体推荐(6) / 图文教程(14) / 笔刷推荐(2) / 字体及笔刷推荐(1) / 新手入门(0)
- 代码块：HUD 风格（等宽字 + 左侧 1px 线 + 无圆角）

### 6.3 全站共存功能

| 功能 | 实现要点 |
|---|---|
| 键盘导航 | `←/→` 切作品，`/` 聚焦搜索，`Esc` 关闭弹层 |
| 明暗模式 | **不做**。基底锁定纸白 —— 混用基底会破坏 Swiss 骨架的一致性 |
| 响应式 | 桌面 3 栏 → 平板 2 栏（主视觉上移）→ 手机单栏（导航折叠为 `01 / 02 / 03 / 04` 纯编号） |
| 无障碍 | 黄 `#E8FF00` 对白底对比度仅 **1.15:1** → **绝不用于正文**。黄底上的文字必须用 `#0D0D0D`（对比度约 17:1） |
| 性能 | 图片全 `webp` + `lazy`；字体 `font-display: swap`；首屏关键 CSS 内联 |
| 元信息 | OG 卡片、`sitemap.xml`、JSON-LD `Person` |
| **明确不做** | 评论区、登录/账号、多语言、暗色模式、博客后台、无限滚动、第三方 UI 库 |

## 7. 内容

### 7.1 结构（来自站点实测）

| 内容块 | 数据来源 | 量 |
|---|---|---|
| 作品集 | `GET /wp-json/oss/v1/images` + `personaldesign` 17 个集合 | 17 集合 / 2264 图（方舟线） |
| 教程笔记 | `GET /wp-json/wp/v2/posts` | 至少 10 篇可见，分类 6 类 |
| 图标库 | `GET /wp-json/icons/v1/list` | 547 个 / 8 包 |
| 关于 | 自撰 | — |

### 7.2 文案调性

**保留**（有实测支撑）：
- 短句、全大写、声明式：`BUILD USEFUL THINGS WITH CODE.` / `DESIGN × CODE × CHAOS`
- 自我描述：`Creative Technologist` / `Developer / Creator` / `Interactive design`
- 伪技术细节：坐标、版本号 `REV 2.6`、状态、时间戳

**新增建议**（基于你的实际内容）：
- 首页主张句候选：
  - `DESIGN EVERYDAY.`（你站点的 slogan，最稳）
  - `ARCHIVING MOTION, ONE FRAME AT A TIME.`（贴合你的作品体量）
  - `17 SETS. 2264 FRAMES. STILL COUNTING.`（用真实数字，最有说服力）

**禁止**：照搬参考稿的 `YOUR NAME` / `JANE DOSE` / `REFINE` —— 它们是占位符，不是品牌资产。

### 7.3 导航命名

```
01 ARCHIVE   ← 作品（"档案"比"作品"更贴你的工程气质）
02 WORK      ← 精选
03 NOTES     ← 教程
04 ABOUT     ← 关于
```
编号即导航标识，同时兼作页面章节标记 —— 编号系统本身是 HUD 语法的一部分。

## 8. 动效

| 类型 | 规格 |
|---|---|
| 入场 | 区块逐个位移淡入，`translateY(24px)→0`，`opacity 0→1`，`600ms` |
| 缓动 | `cubic-bezier(0.22, 1, 0.36, 1)`（先快后缓，机械感） |
| **禁止** | `bounce` / `elastic` / 回弹 —— 与工业气质冲突 |
| 黄带揭示 | 滚动触发 `clip-path` 展开 |
| 箭头 | hover 水平位移 `8px`，`200ms` |
| 状态灯 | 透明度呼吸，`2.4s` 循环 |
| 图片 | 灰度 → 原色，`filter` 过渡 `400ms` |
| 计数切换 | `01 / 04` 数字垂直滚动替换 |
| 降级 | `prefers-reduced-motion: reduce` 时全部关闭 |
