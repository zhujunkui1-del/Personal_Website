## 一、形态与位置 ★（2026-09-13 重写）

> **修正原因**：新设计稿里首页右栏**内嵌**了播放器。
> 作者确认：**首页右栏常驻播放器不需要折叠态**，其他页仍用三态。

### 两套形态

| 页面 | 位置 | 形态 | 尺寸 |
|---|---|---|---|
| **首页** | 右栏第一块，**常驻** | **两态**：主屏 → 歌单展开（**无折叠**） | 主屏 ~498×285，歌单 ~498×660 |
| **其他所有页面** | 贴**页面右边缘**固定 | **三态**：折叠标签 → 主屏 → 歌单展开 | 折叠 54×117 |

### 折叠态规格

```
尺寸      54 × 117 px
位置      贴页面右边缘，垂直居中
外观      **直角实色**竖向小标签（纸白面板 + 1px 描边），内含箭头
激活      箭头朝左 → 面板【向左侧展开】
          不遮挡页面中间内容
```

### 跨页持续播放 ★

```
切页时：音乐不停 · 进度保留 · 音量保留 · 播放模式保留 · 歌单与当前曲目保留

技术要点：
  · 播放器挂在根布局（layout），不随页面卸载
  · 首页右栏那块与其他页的浮层是【同一个播放器实例】
  · 用 React Context 或全局状态共享
  · 路由切换不得重建 <audio> 元素
```

### 三态结构（其他页用）

| 状态 | 尺寸 | 形态 |
|---|---|---|
| ① 折叠 | 54 × 117 | 贴右边缘的**直角实色**竖向小标签，只显示箭头 |
| ② 主屏 | ~498 × 285 | 左栏元数据 + **中央黑胶** + 右栏信息 + 两行控制 |
| ③ 歌单 | ~498 × 660 | 主屏不变，下方滑出歌曲列表（含搜索框） |

| 虚拟滚动 | 100+ 首性能 |

### 默认静默 ★

```
进入网站时：【不播放任何音乐】
必须由用户主动操作播放器（点播放键）才会出声
默认音量：40%
```

**理由**：
- 浏览器本身就禁止无交互自动播放（会抛 `NotAllowedError`）
- 访客可能在公共场合或静音环境，突然出声是打扰
- 播放器常驻但不主动发声，符合「安静的工具」定位

> **技术注意**：`<audio>` 元素**不设置 `autoplay` 属性**。
> 播放必须由真实的用户手势（click / keydown）触发，
> 否则即使调 `play()` 也会被浏览器拒绝。

## 七、技术要点

| 项 | 方案 |
|---|---|
| 音频 | 原生 `<audio>`，**不引第三方播放器库** |
| 黑胶旋转 | CSS `@keyframes` + `animation-play-state: paused/running` |
| 面板材质 | **纸白实色** —— `background: #F9F9F9` + `border: 1px solid #0D0D0D`（或极淡 `rgba(13,13,13,0.12)`） |
| 数据 | 静态 JSON（`tracks.json`） |
| 封面 | 从音频 ID3 读取，或 JSON 指定路径 |
| 虚拟滚动 | 手写或轻量库（100+ 首必须） |
| 状态 | `localStorage` |
| 预加载 | `preload="metadata"` |
| 无障碍 | `aria-label`、键盘可操作、`prefers-reduced-motion` 时关旋转 |

### 数据结构
```json
{
  "tracks": [
    {
      "id": "track-01",
      "title": "南京夜无电波讯号",
      "artist": "花水r;洛天依",
      "album": "黑色磁带",
      "src": "/audio/track-01.mp3",
      "cover": "/audio/track-01-cover.jpg",
      "duration": 178.7
    }
  ]
}
```
> 字段与 MP3 内嵌 ID3 标签一致（曲名 / 艺术家 / 专辑 / 封面），构建时可自动提取。

### 音质提示
**128 kbps 属于偏低码率**（常见标准为 192–320 kbps）。在好一点的耳机或音箱上可能有可感知的压缩感。若在意音质，建议换成 320 kbps 或无损源。
