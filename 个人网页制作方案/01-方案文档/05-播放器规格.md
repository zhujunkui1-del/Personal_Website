## 四、视觉规范

### 样式例外声明
播放器是**全站唯一允许「圆角 + 玻璃拟态」的组件**。
其余所有页面、组件仍严格遵守零圆角、无模糊、无阴影。

| 项 | 规格 |
|---|---|
| 圆角 | **允许**（沿样例图） |
| 材质 | **玻璃拟态** —— 半透明背景 + `backdrop-filter: blur()` |
| 高亮色 | **酸性黄 `#E8FF00`**（改自样例图的绿色） |
| 折叠态 | 竖向玻璃标签，`‹` 箭头 |
| 黑胶 | 圆形，中央贴专辑封面图，**无封面时不显示唱片** |
| 黑胶旋转 | 播放时持续旋转；暂停时停住；继续时从停住角度接着转 |
| 唱臂 | 不做 |
| 进度条 | 细长条 + 圆形拖拽柄（沿样例图） |
| 音量 | 喇叭图标 + 横向滑块 |

### 与原站点的协调
- 播放器的**黄高亮**与全站强调色一致 —— 不会显得孤立
- 玻璃材质在纸白背景上会呈现浅灰半透明，与站点基调仍能共存

## 七、技术要点

| 项 | 方案 |
|---|---|
| 音频 | 原生 `<audio>`，**不引第三方播放器库** |
| 黑胶旋转 | CSS `@keyframes` + `animation-play-state: paused/running` |
| 玻璃效果 | `backdrop-filter: blur(20px)` + `rgba()` 背景 |
| 数据 | 静态 JSON（`tracks.json`） |
| 封面 | 从音频 ID3 读取，或 JSON 指定路径 |
| 虚拟滚动 | 手写或轻量库（100+ 首必须） |
| 状态 | `localStorage` |
| 预加载 | `preload="metadata"` |
| 无障碍 | `aria-label`、键盘可操作、`prefers-reduced-motion` 时关旋转 |

### 数据结构
```json
{
  "tracks": [
    {
      "id": "track-01",
      "title": "南京夜无电波讯号",
      "artist": "花水r;洛天依",
      "album": "黑色磁带",
      "src": "/audio/track-01.mp3",
      "cover": "/audio/track-01-cover.jpg",
      "duration": 178.7
    }
  ]
}
```
> 字段与 MP3 内嵌 ID3 标签一致（曲名 / 艺术家 / 专辑 / 封面），构建时可自动提取。

### 音质提示
**128 kbps 属于偏低码率**（常见标准为 192–320 kbps）。在好一点的耳机或音箱上可能有可感知的压缩感。若在意音质，建议换成 320 kbps 或无损源。
