## 二、自定义 REST 接口（可直接调用，无需鉴权）

基址：`https://www.ignoredone.space/wp-json`

### 2.1 图标库
```
GET /icons/v1/list
    → { success, count: 547, packs: { default: [308], iconpack1: [42], iconpack2: [39],
        iconpack3: [32], iconpack4: [32], iconpack5: [32], iconpack6: [32], iconpack7: [30] } }
    每项: { id, name, url }

GET /icons/v1/download-pack/{pack}      # 整包下载，pack 为包名
    pack 取值: default | iconpack1 … iconpack7
```
图标 CDN 直链规律：`https://cdn.ignoredone.cn/icon/{pack}/{0000..}.png`
（`default` 包无子目录：`https://cdn.ignoredone.cn/icon/0000.png`）

### 2.2 明日方舟美术资源
```
GET /oss/v1/images
    → [ { year, title, cover, images: [url...], count, path } ]   # 94 个集合
```
- 按年份：2019:6  2020:10  2021:12  2022:11  2023:12  2024:16  2025:14  2026:13
- 图片总数：**2264**
- 路径规律：`https://cdn.ignoredone.cn/arknightsdesign/{year}/{MMDD}/{001.jpg…}`
- 封面带 OSS 处理参数：`?x-oss-process=image/format,webp/quality,q_80`

### 2.3 字体库
```
GET /wp/v2/font_library?per_page=100
GET /wp/v2/font_category?per_page=100
GET /wp/v2/font_library/{id}
```

### 2.4 其他
```
GET /ignoboard-manual/v1/content          # IgnoBoard 使用手册 HTML
GET /wp/v2/media                          # 媒体库（含 ignoboard-v1.1.1~1.1.3.zip）
GET /wp/v2/pages  /wp/v2/posts            # 标准接口（见下方注意）
```

> ⚠️ **注意**：站点装了过滤器，`per_page` 被强制上限为 **10**，分页无法翻到更多。
> 要拿具体条目，用 `?slug=xxx` 反而会被忽略（实测所有 slug 查询都返回同一条 id=7223）。
> 可靠办法：直接按已知 ID 取 `/wp/v2/pages/{id}`，或用自定义接口。

## 六、对「个人网页」项目的可用价值

1. **配色权威来源**：站点首屏就是 **5 个纯黄圆点 `#FFD400 ~ #FFE000` + 纯黑巨型字 + 纯白底**，与 `DESIGN.md` 里"酸性荧光黄主导"的判断一致 —— 这是你自己的视觉基因，不是外部模仿
2. **字体可直接用**：站内已自托管 `Outfit` 与 `Google Sans Flex`，与 `DESIGN.md` 推荐的 Neo-Grotesque 方向吻合
3. **图标库 547 个可直取**：CDN 直链无需鉴权，做网站 UI 图标够用
4. **作品图按需取用**：`oss/v1/images` 一条请求拿到全部 94 个集合的封面与图组，可直接驱动首页作品区
5. **动态数据能力参考**：该站把作品数据放在自定义 REST 接口 + OSS，前端 JS 渲染 —— 这是「个人网页」后续可复用的架构模式
